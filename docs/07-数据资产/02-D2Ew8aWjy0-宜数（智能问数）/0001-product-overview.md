# 产品概述

## **产品简介**

### **宜数（智能问数）是什么？**

宜数（智能问数）是大模型驱动的智能数据分析产品，致力于打造数据智能消费新范式，盘活企业数据资产，为客户提供“盘资产（数据工厂）、知数据（对话式数据分析）、酷体验（智能互动大屏）、易协同（数据驱动运营）”一站式数据智能解决方案，实现数据驱动组织管理和业务运营。

## **产品亮点**

| **能力** | **说明** |
| --- | --- |
| **数据工厂** | 提供数据集成、数据处理能力，支持企业构建高质量、AI友好型的数据集。  image |
| **无代码调优** | 通过专业名词、业务逻辑、样例库、表选择等配置，将企业的业务知识和使用习惯等信息提供给大模型，让AI助理更懂业务，提升问数准确度。  image |
| **智能洞察** | 通过自然语言快速生成图表，支持用户一句话生成数据报告。  image |
| **互动大屏** | 问数助理联动数据大屏，让大屏数据“活”起来。  image |

## **场景案例**

### **【云南白药】设备管理助手**

云南白药基于宜数打造了设备管理助手，支持一线员工通过自然语言对话实时进行数据分析，也实现了设备大屏的实时对话交互，并且在设备有异常的时候也会实时追踪并且进行提醒。

[](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20241216/azcsvd/%E4%BA%91%E5%8D%97%E7%99%BD%E8%8D%AF.mp4)

### **【长龙航空】航班信息管理助理**

通过过宜数，长龙航空创建了“航班信息管理助理”，实现了航班数据的实时分析和高效管理。工作人员不仅可以与 AI 助理直接对话，还可以与互动大屏进行数据咨询、数据问答和数据分析，大幅提升了航空运营的智能化水平和决策效率。

## **开通方式**

1. 在钉钉工作台右上角的“应用中心“搜索“宜数（智能问数）”。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6935754371/p889325.png)
2. 主子管理员可以直接安装使用，普通员工需要向主子管理员申请安装。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6935754371/p889326.png)
3. 安装后即可使用。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6935754371/p889329.png)
