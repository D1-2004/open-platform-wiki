# 基础信息配置

## **概述**

基础信息配置主要用于引导用户如何使用问数助理，主要包括以下几个方面的信息配置：

- 助理基础信息：支持头像、名称、描述的自定义
- 欢迎语和开场白：支持配置一段文字来介绍助理的功能和定位，还可以配置推荐指令引导用户开启对话

## **功能价值**

降低用户使用问数助理的上手门槛。

## **适用场景**

### **场景 ：搭建一个IPD产品研发分析助理，实现数据智能分析**

#### **功能使用效果**

用户第一次使用的时候可以快速了解该助理的职能范围，并快速上手使用。

![图片 1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8935754371/p888843.png)

#### **功能搭建流程**

1. 配置头像、名称、描述。
2. 配置欢迎语。
3. 配置开场白，字数在30个以内。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2770954371/p890509.png)
