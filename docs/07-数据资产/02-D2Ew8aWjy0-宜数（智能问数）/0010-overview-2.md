# 概述

## **什么是互动大屏**

互动大屏由传统数据大屏和问数助理两部分构成，传统数据大屏支持用户自由配置炫酷大屏用于数据展示，同时支持企业将问数助理与数据大屏进行联动，让大屏数据“活”起来，以满足个性化数据分析诉求。

## **互动大屏解决什么问题**

1. **数据可视化效果差**：传统BI报表可视化效果差，达不到汇报展示效果
2. **个性化数据分析难**：传统数据大屏只能展示固定的分析维度和指标，无法匹配业务的发展变化，一旦KP想要进行个性化分析时无法快速拿到分析数据
