# 自定义仪表盘

本文档主要介绍数据资产平台中自定义仪表盘的功能。

## **什么是自定义仪表盘**

[自定义仪表盘（Dashboard）](https://open-dev.dingtalk.com/fe/daas#/myDashboard)是数据可视化工具，用于汇总、监控和分析关键业务指标和数据。它能够以直观、易懂的方式展示多个指标和数据集，提供实时更新和交互功能，帮助用户迅速了解当前业务状态，并支持作出决策和采取行动。

## **为什么使用自定义仪表盘**

- **数据汇总和可视化**：仪表盘能够从钉钉预置的不同数据源中汇总、整理并自定义展示指标和数据，以图表、表格等形式展示便于更好理解数据。钉钉提供了各类官方仪表盘，用户可以基于官方仪表盘快速搭建出属于自己的个性化报表。
- **预警和提醒功能**：仪表盘可以设置警戒线和预警规则，当指标或数据超出设定的范围时，可及时提醒用户并触发相应的行动。
- **发布分享**：用户可以将仪表盘的图表和分析结果分享链接给其他人进行查看和交流。

综上所述，仪表盘通过数据可视化和交互功能，帮助用户快速了解业务情况，并支持决策和行动。其功能的具体实现可以根据不同的业务需求和用户需求进行定制。

## **操作步骤**

### **步骤一：新建仪表盘**

1. 登录[数据资产平台 > 自定义仪表盘](https://open-dev.dingtalk.com/fe/daas#/myDashboard)。
2. **通过官方模板新建仪表盘**：

   - 数据资产平台提供了官方模板，你可以点击查看官方模板数据。
   - 可以通过单击 **“...” > 复制**实现快速创建官方模板仪表盘。创建完成后，即可在下方自定义仪表盘列表中进行查看。
   - **通过单击下方新建仪表盘，**创建仪表盘。

     ![新建仪表盘.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8287946871/p715899.png)

### **步骤二： 创建图表/组件**

#### **添加指标卡**

指标卡：用于展示关键指标和其对应的目标值进行比较，以便用户能够直观地了解业务绩效状况、追踪进度和识别问题。

![自定义仪表盘指标卡.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8287946871/p715902.png)

1. 单击**指标卡**，在弹出添加指标卡页面，单击 **+ 点击添加**，完成数据源添加。

   ![添加指标卡数据源.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8287946871/p715903.png)
2. 选择平台预制的**指标**，**指标**用于统计**。**
3. 选择数据时间范围，可选择时间范围包含：近7天/近一月/近3月/近半年。
4. （可选）选择数据过滤：可过滤非必要数据干扰。
5. （可选）推荐设置图表名称，方便后续查看对应数据指标。
6. （可选）单击 **+ 点击添加，**完成订阅添加**。**可按照设定条件，发送动态卡片给固定人或群。

![表格自定义.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8287946871/p716183.png)

2. 选择平台预制的**显示字段**。
3. 选择数据时间范围，可选择时间范围包含：近7天/近一月/近3月/近半年。

### **步骤三：保存并发布仪表盘**

**保存并发布仪表盘**：保存仪表盘后，图表设置的订阅功能生效。单击**发布**可以选择仪表盘的查看人并支持分享链接。

![保存并发布自定义表盘.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8287946871/p716153.png)

#### **权限设置**

- **仪表盘权限：**

  1. **主管理员可以查看和编辑所有仪表盘。**
  2. **非主管理员只能查看和编辑自己创建的仪表盘。**
  3. **创建人发布时为A员工添加权限，则A员工仅有查看权限，没有编辑权限。**
  4. **官方仪表盘复制后，操作人支持编辑。**
- **数据权限：**

  1. **主管理员支持查看所有数据。**
  2. **非主管理员仅可查看该部门/该个人的数据，比如一份部门维度的考勤数据，主管理员可以看到全公司的部门考勤数据，非主管理员只能看到自己部门的考勤数据。**

## **名词解释**

| **名词** | **说明** |
| --- | --- |
| **官方模板** | 钉钉官方基于通用场景定义的基础仪表盘，满足客户的初级分析场景。 |
| **数据源** | 仪表盘中数据分析的来源，主要是数据资产平台加工好的统计数据和明细数据。 |
| **数据表** | 钉钉官方预置的数据项集合，包括：统计数据和明细数据。 |
| **指标** | 数据报表中用于衡量和评估的数值量。可以用来量化或描述感兴趣的特定数据。通常用于定义图表的纵轴或数值轴，以展示不同维度下的指标数值。 |
| **维度** | 维度表示数据分析中用于分类、分组或筛选数据的属性或变量。通常用于定义图表的横轴或分组条件，以探索不同维度下的数据变化情况。 |

## **常见问题**

- **发布和保存有什么区别？**

答：发布是指将该仪表盘以链接的形式分享给其他人查看；保存是指将仪表盘的配置进行保存。

- **如果管理员和我在同时编辑仪表盘最后按谁都为准？**

答：按照最新的操作进行更新。

- **订阅图表什么时间生效？**

答：订阅图表的触发条件在保存仪表盘时生效。

- **怎样将整个仪表盘订阅发送到群内？**

答：当前仅支持将单个图表订阅发送到群，暂不支持发送整个仪表盘。
