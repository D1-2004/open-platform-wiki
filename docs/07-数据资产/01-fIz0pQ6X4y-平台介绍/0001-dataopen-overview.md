# 什么是数据资产平台

本文档介绍钉钉数据资产平台相关概念。

## 什么是数据资产平台

[钉钉数据资产平台(dPaaS)](https://open-dev.dingtalk.com/fe/daas)通过**低成本、可扩展、易维护**的数据普惠理念，简化了企业建设和管理数据资产的过程，为企业提供统一的数据集成、管理、消费等能力，**通过数据驱动组织治理和业务经营，致力于打造数据消费新方式，进一步提升企业竞争力和创新能力**。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7947693961/p715687.png)

平台**内置钉钉全域的数据资产**，支持与企业内部数据、外部生态数据的**融合分析**，支持数据可视化、数据指标预警、以及数据智能等，让开发者可以轻松构建数据驱动的应用，帮助企业更好的实现数据管理和决策。

## **平台优势**

- **钉钉数据资产开放**：平台内置10大业务域，30多个业务场景，1000多个数据项，支持企业快速分析组织效能，业务经营情况等。

  ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3983439961/p735776.png)
- **零代码报表搭建**：拖拉拽灵活配置仪表盘，“数找人”，仪表盘可被分享到单聊/群聊/OA审批等高频协作场，看数更便捷。

  ![自定义仪表盘.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3983439961/p735801.png)
- **数据指标预警**：通过定时订阅或条件订阅数据指标，让员工及时了解数据变化，推动业务问题快速解决。

  ![image.gif](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3983439961/p735810.gif)
- **数据智能分析**：结合大模型能力，用自然语言的方式，获取数据资产平台的数据快速生成报表，进一步降低数据分析的成本。

  ![8ab279d4123d1a5a0124a2bb6e956209.gif](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2983439961/p735820.gif)
