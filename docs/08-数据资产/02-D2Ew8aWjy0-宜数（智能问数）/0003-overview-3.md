# 概述

## **什么是问数助理**

问数助理是指通过自然语言对话的方式进行数据分析，核心解决企业的个性化数据分析诉求，以应对快速的业务变化，实现数据驱动组织管理和业务运营。

### **适用场景**

1. 通用场景：用户有数据分析相关诉求，例如想整理分析钉钉上的数据使用情况，企业的自有数据分析等都支持。
2. 垂直场景：门店店长助理、导购助理、销售助理等场景的数据分析诉求也可以被满足。

## **问数助理解决了什么问题**

1. **报表开发效率低**：一份高质量的报表需要业务人员、技术人员等多个角色参与，建设周期长、开发效率低，往往需要几天甚至几周
2. **数据可视化成本高**：传统的数据可视化需要技术人员介入，并且要具备一定的数据分析和图表制作的能力，实现门槛较高
3. **数据理解门槛高**：没有数据基础的普通人面对复杂的报表时，无法快速得出有效的洞察结果，难以直观地理解和分析数据
4. **个性化数据分析难**：传统BI报表只能展示固定的分析维度和指标，无法匹配业务的发展变化，一旦KP想要进行个性化分析时无法快速拿到分析数据
