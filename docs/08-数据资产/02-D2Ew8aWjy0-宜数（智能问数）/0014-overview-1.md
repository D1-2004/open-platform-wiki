# 概述

## **什么是数据工厂**

数据工厂支持用户集成企业自有数据，并进行数据清洗加工等操作，以构建高质量的AI友好型数据集供业务场景消费。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0870954371/p890618.png)

## **数据工厂解决什么问题**

1. **数据孤岛问题**：企业内部往往存在多个数据源，如不同的数据库、文件系统、云存储等，数据工厂通过统一的平台将这些分散的数据源集成在一起，打破数据孤岛，实现数据的集中管理和消费。
2. **数据质量低口径不一致**：数据工厂提供数据清洗和验证功能，可以去除无效或错误的数据，确保数据的质量和一致性。这对于后续的数据分析和决策至关重要。
3. **数据处理难度高**：传统的 ETL（Extract, Transform, Load）过程通常需要大量的手动操作和复杂的脚本编写，数据工厂通过图形化界面和预置的数据处理组件，简化了 ETL 过程，实现了数据处理的自动化，减少了人为错误和维护成本。
