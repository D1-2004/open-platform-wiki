# 授权数据使用

本文档主要介绍数据资产平台中生成数据图表的功能。

## **功能简介**

为了实现企业自建应用数据和第三方企业应用的融合，让第三方企业应用更好地服务客户，授权数据到钉钉生态应用后，生态应用能够直接获取到授权字段的数据。

[](https://cloud.video.taobao.com/play/u/null/p/1/e/6/t/1/404186796072.mp4?SBizCode=xiaoer)

## **步骤一：选择相应的待授权模型**

1. 选择**创建数据服务**，单击**去授权**。

   ![待授权模型](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0013171861/p632091.png)
2. 选择需要授权的模型数据。

   ![选择需要授权的数据](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0013171861/p632466.png)

### **步骤二：配置字段，并授权**

1. 配置映射，并确认发布。

   ![映射配置](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0013171861/p632471.png)
2. 点击同意授权协议，点击授权即可。

   ![授权成功](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0013171861/p632477.png)
3. 授权成功的申请，可以在**已授权**中查看，三方应用就可以获得管理员授权的这些字段数据。

   ![报销数据查看](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0013171861/p632483.png)
