# 摄像头反向二维码接入

## 1.头文件

```
#include "dtiot_netconfig_bind_service.h"
```

## 2.摄像头配网接入

**场景：**摄像头扫描到二维码后，通过二维码获取需要连的wifi的信息

**函数：**

```
int (*camera_bind_get_wifi_by_qrcode)(char qrcode[DEVICE_QR_CODE_LEN], dtiot_wifi_info_t *wifi_info);
```

**参数：**

```
//扫描的二维码
char qrcode[DEVICE_QR_CODE_LEN];

//调用方传入wifi 信息的指针
dtiot_wifi_info_t *wifi_info

详细请参考头文件。
```

## 3.设备配网成功

**场景：**待wifi连接成功后，设置网络状态

**函数:**

```
int (*set_net_status)(int net_status);
```
