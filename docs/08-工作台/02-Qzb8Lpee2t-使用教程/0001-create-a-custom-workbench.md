# 创建自定义工作台

本文档介绍自定义工作台创建的流程。

## **操作流程**

1. 登录[钉钉开发者后台](https://open-dev.dingtalk.com/)。
2. 点击开放中心，选择工作台。![iShot2022-12-20 15](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0116761761/p536988.png)
3. 工作台页面，右侧点击“+设计器项目”。

   > **[!NOTE]**
   >
   > 有自定义工作台权益的才能看到此界面；权益问题详见 [6.工作台权益已失效](0042-faq.md)
   >
   > 如果工作台是通过产品方案商开通的，不支持客户自己创建项目。可直接查看对应项目进行编辑。

   ![创建设计器搭建自定义工作台1108.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8715169961/p736056.png)
4. 填写自定义工作台名称和备注，点击创建，即可生成。![iShot2022-12-20 15](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0116761761/p536994.png)
5. 自定义工作台项目支持分端编辑，可单独进入移动详情或PC详情编辑，同时支持项目重命名、删除，支持按工作台名称（即项目名称）进行模糊搜索，已启用的项目会默认展示在最前面，方便快速编辑调整。

![1108自定义工作台项目列表使用.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9715169961/p736063.png)
