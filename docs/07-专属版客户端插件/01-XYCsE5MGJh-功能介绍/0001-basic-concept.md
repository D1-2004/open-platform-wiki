# 概述

本文档旨在指导开发者如何开发、接入并发布专属插件，涵盖背景说明、核心概念、开发流程、安全规范及常见问题，帮助开发者高效完成集成工作。

## 什么是专属插件

**专属插件**是面向专属版钉钉定制App的扩展功能包。企业可通过该机制，将自有功能（如VPN连接、安全沙箱、原有App业务模块等）封装成符合钉钉开放规范的SDK，并以插件形式集成至专属版钉钉中，从而可以让企业员工更好的使用专属版钉钉。

插件基于钉钉开放框架中的扩展点（ExtensionPoint）机制实现，在运行时由钉钉客户端动态加载和调用，具备良好的隔离性与可维护性。

## **应用场景**

### 场景一：第三方服务集成

假如你是VPN服务商，你可以使用钉钉客户端开放能力将产品封装成VPN插件，并提供给客户发布到专属钉钉打包平台用于集成。

### 场景二：企业内部系统融合

假如你是企业内部开发者，你的企业购买了专属版钉钉，你可以将公司原有App的核心功能抽离为独立SDK，再通过适配层封装为专属插件，嵌入钉钉主流程，实现原有业务同钉钉的深度融合。

### 场景三：原生能力补充H5/小程序

假如你的企业在开发H5/小程序应用时，需要用到一些必须通过原生开发才能提供的能力时，你可以开发专属插件并自定义JSAPI，前端应用就可以通过JSBridge调用到你的SDK里面的代码从而完成业务开发。

## 名词介绍

| **名词** | **描述** |
| --- | --- |
| 模块（Bundle） | 符合扩展规范的代码集合。 |
| 扩展点（ExtensionPoint） | 钉钉平台业务模块对外开放的定制点。 |
| 扩展（Extension） | 一个扩展点的具体实现，即钉钉客户端插件中实现。 |
| 服务（Service） | 钉钉平台对外暴露的功能接口，供插件或其他模块调用。 |
| 事件（Event） | 钉钉平台对外抛出的事件，比如App前后台事件、账号登录/登出事件。 |

## 安全与合规说明

请严格遵守以下安全与权限使用规范，违规行为可能导致插件被禁用或禁止插件运行。

### **关于权限**

- 必须遵循最小权限原则，合理申请系统权限。
- 在用户同意钉钉隐私政策前，禁止采集任何个人隐私数据或调用涉及隐私的API。
- 初始化阶段不得直接申请敏感权限；必须在具体业务场景中按需申请，并使用钉钉提供的权限申请接口。
- 对相机、设备信息、存储等敏感权限，上架时须明确说明使用目的和业务场景。

### **关于安全**

- 严禁 hook 钉钉平台相关代码。
- 禁止添加非插件业务必需的私有操作，如 hook 系统接口、dump 用户设置等。
- 未经客户或钉钉授权，禁止将钉钉相关信息上传至远程服务器。
- SDK 不得将用户行为日志、个人信息、组织架构等敏感信息打印至日志。
- 对于使用Java hook、Native hook、VirtualApp、Application代理等非常规技术，集成前需向钉钉侧详细说明使用场景，避免与平台安全检测机制冲突。
- iOS平台禁止使用已被标记为废弃的系统类或API（如UIAlertView），建议替换为UIAlertController以防止闪退。
- iOS平台禁止使用自行创建WKWebView实例；所有Web页面必须使用钉钉提供的H5容器，否则可能导致网络请求失败或页面异常。

## 常见问题

### **原有App或SDK，集成到专属版钉钉中主要困难点**

主要挑战在于双方依赖库版本冲突。建议优先将你的代码依赖调整为钉钉客户端所使用的版本，并重新测试功能完整性。若必须保留原有版本，请联系钉钉技术共同评估影响范围并制定解决方案。

### **集成开发需要多久？**

开发周期主要取决于以下三个方面：

- 将原有代码剥离并改造成可供外部调用的SDK。
- 解决依赖库与钉钉基础环境的版本冲突。
- 在钉钉平台上完成功能开发、调试与迭代测试。

综合来看，中等复杂度的SDK从接入到稳定交付，通常需要约1个月时间。建议提前规划项目排期，预留充足的联调与验证周期。
