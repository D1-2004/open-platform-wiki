# 接入流程

钉钉提供了线上问题监控及发布监控。应用测试完成后，即可接入钉钉的监控中心进行监控。

## 小程序接入

1. 登录[开发者后台](https://open-dev.dingtalk.com/)。
2. 找到已创建的小程序，在应用详情页，单击**监控中心**。
3. 单击**添加**添加对应的业务负责人。

   ![监控中心](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2129017161/p254049.png)
4. 添加成功后，单击**查看监控大盘**，即可以看到监控。

   ![查看监控大盘](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2129017161/p254053.png)

## H5微应用

1. 登录[开发者后台](https://open-dev.dingtalk.com/)。
2. 找到已创建的H5微应用，在应用详情页，单击**监控中心**。
3. 配置应用负责人，然后单击**加入监控**。

   ![接入监控](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2129017161/p254059.png)
4. 单击**复制**代码，然后添加代码到微应用需要添加监控的页面的`<header></header>`标签中，并发布到线上。

   ![p254061](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2129017161/p258868.png)
5. 添加成功后，单击**查看监控大盘**，即可以看到监控。

   ![页面访问监控](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4931846161/p254066.png)
