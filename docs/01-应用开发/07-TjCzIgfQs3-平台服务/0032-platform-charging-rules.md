# 平台收费规则

平台收费主要是保证金和技术服务费，技术方面的收费包括阿里云部署资源收费等。

## 保证金

保证金是指产品方案商入驻钉钉时所缴纳的一定金额的款项，用以作为服务商在合作期内为用户提供诚实守信的应用服务的担保。

缴纳保证金的意义在于：保障用户权益，提升服务商的服务品质和产品技术体验。

## 技术服务费

应用完成上架，当客户购买应用，钉钉会收取技术服务费，具体比例如下图所示：产品方案商就是指开发SAAS的服务商，渠道指销售部署商，可售卖ISV产品。

![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9780288561/p470597.png)

- 举例①：客户购买了1款直销应用（宜搭），30天后，订单进行结算，服务商可以拿到客户付款金额\*85%的钱，钉钉拿到客户付款金额\*15%的钱。
- 举例②：客户从渠道商那里购买了1款应用（宜搭），30天后，订单进行结算，那服务商可以拿到客户付款金额\*40%的钱，渠道商可以拿到客户付款金额\*30%的钱，钉钉可以拿到客户付款金额\*30%的钱。
