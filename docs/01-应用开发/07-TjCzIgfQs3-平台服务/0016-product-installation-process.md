# 产品发布流程

本文档介绍如何在开发者后台完成产品的发布流程，涵盖前提条件、操作步骤及注意事项，帮助开发者高效、规范地提交应用并通过审核。

## 前提条件

第三方个人应用产品发布前，应用归属的钉钉组织需满足以下条件：

- 钉钉组织需完成高级认证。
- 钉钉组织需完成产品方案商入驻。

## 发布流程

1. 登录[开发者后台](http://open-dev.dingtalk.com/)，然后依次进入**应用开发** > **第三方个人应用**。

   ![p165984](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7635460261/p256818.png)
2. 点击要发布的应用，点击**版本管理**，选择需要提交审核的版本。

   ![p190704 ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2165038161/p256782.png)
3. 点击**提交审核**。

   > **[!NOTE]**
   >
   > 如果没有进行钉钉组织认证和服务商认证，会提示先进行认证。您可以按照开发者后台提示流程进行认证，也可以参考[合作全流程指引](0027-isv-cooperation-guide.md)。
4. 在产品审核页面，依次进行安全扫描、产品审核等。![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8842462061/p165987.png "image.png")

   1. 单击安全扫描下的**点击进入**，对提交应用进行安全扫描，并将展示安全扫描报告。![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8842462061/p165988.png "image.png")
   2. 查看产品审核标准，可以查看第三方个人应用的产品设计规范，见[产品设计规范](0015-product-design-specification.md)。
   3. 单击提交审核下的**点此进入**，提交审核。![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8842462061/p165989.png "image.png")
