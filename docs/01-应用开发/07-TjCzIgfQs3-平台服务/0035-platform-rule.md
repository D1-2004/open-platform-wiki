# 平台规则

上架到应用市场的应用，需要学习平台规则，包括应用等级权益和应用汰换规则。

## 应用等级权益

为帮助生态伙伴健康成长，钉钉开放平台推出成长等级体系。等级判定对象为单个独立应用（已上架到钉钉应用市场），不同等级的应用享有不同的权益。

通过以下路径查看等级权益：在钉钉**工作台**进入**自运营平台**，依次单击**平台规则 > 等级权益 > 查看等级规则**。![测试](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7542088561/p468099.png)

## 应用汰换规则

应用考核未通过的结果：

- 应用不在应用市场展示，仅支持客户主动搜索。
- 严重情况，将直接从应用市场下架。

通过以下路径查看应用汰换规则：在钉钉**工作台**进入**自运营平台**，依次单击**平台规则 > 应用运营考核 > 查看考核规则**。![测试2](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7542088561/p468101.png)
