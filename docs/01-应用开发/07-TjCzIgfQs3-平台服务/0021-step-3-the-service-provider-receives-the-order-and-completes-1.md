# 步骤三：服务商接单并完成订单交易

当客户完成自定义工作台委托后，服务商可查看客户委托的工作台信息并完成订单交易。

1. 服务商登录[开发者后台](https://open-dev.dingtalk.com/)
2. 依次选择**定制服务>工作台定制>自定义工作台**，选择交付状态为**客户已委托**，此时在列表中可查看到客户委托的工作台信息，如下图所示：

   ![定制门户](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5776275261/p262387.png)
3. 点击**下单**，进入委托定制下单页面，选择所需的规格信息，勾选**阅读并同意**，并点击**确认下单**提交订单。

   ![提交订单](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5776275261/p229909.png)
4. 试用订单提交后即刻可开始进行工作台设计和搭建，正式订单提交后，服务商可在24小时内完成在线支付，或通知客户完成支付，待支付状态如下图所示：

   ![待支付](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2816432161/p229910.png)
5. 完成支付后，即可开始进行工作台的设计和搭建。
