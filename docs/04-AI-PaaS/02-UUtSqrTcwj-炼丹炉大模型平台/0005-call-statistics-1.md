# 调用统计

本文档介绍数据统计相关说明。

调用统计功能可以用来展示不同业务空间和不同模型的调用次数统计和调用量统计，界面示意如下。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3686129171/p813634.png)

- **推理tokens消耗明细：**所有模型被调用时的消耗统计信息，包含API调用、体验中心测试、AI助理调用等。
- **训练tokens消耗明细：**在炼丹炉平台训练专属大模型的消耗统计。
