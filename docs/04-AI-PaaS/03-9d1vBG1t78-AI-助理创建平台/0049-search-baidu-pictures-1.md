# 搜索百度图片

如果你需要使用搜索百度图片的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **操作步骤**

1. 单击**选择执行动作**，选择**资讯搜索** > **搜索百度图片**。

   1. 配置内容：

      | **配置项** | **说明** |
      | --- | --- |
      | 关键词 | 输入想要搜索的关键词，如“小猫”、“大海”等。 |
      | 图片数量 | 每页返回的图片数量，默认值为5，最大值为30。 |
      | 页码 | 输入数字表示你想返回第几页的图片，默认值为第1页。例如，当图片数量为30，搜索页码为5时，就返回第5页的30张图片。 |

## **示例**

以搜索小猫照片为例，配置内容如下：

1. 搜索百度图片：

   | **配置项** | **说明** |
   | --- | --- |
   | 关键词 | 输入：小猫。 |
   | 图片数量 | 输入：5。 |
   | 页码 | 输入：1。 |
2. 此时，你可以在后续步骤引用搜索到的图片列表。如需在卡片中输出每张图片信息，推荐选择AI助理回复互动卡片 > 从模板生成 > 自定义渲染卡片。

   | **配置项** | | **说明** |
   | --- | --- | --- |
   | 生成方式 | | 选择：从模板生成 |
   | 选择模板 | | 选择：自定义渲染卡片 |
   | 配置自定义渲染卡片内容元件与字段 | 卡片标题 | 保持按钮关闭 |
   | 卡片元件 | 选择：图片 |
   | 卡片字段内容 | 图片地址：  - 选择：动态条数 - 数据项：引用“图片列表” |

此时，你已完成百度图片搜索，并在卡片中展示。
