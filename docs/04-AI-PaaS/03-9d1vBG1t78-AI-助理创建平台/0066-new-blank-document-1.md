# 新增空白文档

如果你需要使用新增空白文档的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **操作步骤**

1. 单击**选择执行动作**，选择**钉钉文档 > 新增空白文档**。
2. 配置**新增空白文档**执行动作：

   | **配置项** | **说明** |
   | --- | --- |
   | 新增到 | 选择你需要新增的文档地址。 |
   | 新增类型 | 选择新增的文档类型：  - 文档 - 表格 - 多维表 - 脑图 - 白板 **[!NOTE]**  支持单击“⊕”，进行动态引入 “+” 或 “-”，动态引入的内容必须是“+” 或 “-”之一。否则出现执行错误的错误提示。 |
   | 新增文档标题 | 输入新增的文档标题。  **[!NOTE]**  支持手动输入或单击 “⊕” 引用动态变量。 |

## **示例**

已为自己创建周报文档为例，配置执行动作：

| **配置项** | **说明** |
| --- | --- |
| 新增到 | 选择钉钉文档下“我的文档”。 |
| 新增类型 | 类型选择：文档。 |
| 新增文档标题 | 周报文档。 |

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7729549171/p815244.png)

此时，一个名为“周报文档”的空白内容文档就已经创建成功了。
