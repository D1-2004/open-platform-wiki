# 变量概述

如果你需要了解变量相关知识，你可以参考本文档内容，初步认识工作流变量。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **介绍**

变量是工作流的执行动作中支持引用和修改的数据，包括系统变量、步骤变量和记忆变量。

## **步骤变量**

步骤变量是工作流的前置步骤中的输出数据，可以在后续的步骤中引用的变量。

默认步骤变量有：

| **内容** | | **说明** |
| --- | --- | --- |
| 用户信息 | staff id | 钉钉用户的 UserID 信息。 |
| 姓名 | 用户当前组织的姓名。  image |
| 昵称 | 用户名称信息。  image |
| 对话输入原文 | | 用户输入信息。 |

## **系统变量**

系统变量是系统预置的、与工作流前置步骤无关的数据，支持在后续的步骤中可以引用的变量。

默认系统变量有：

| **内容** | **说明** |
| --- | --- |
| 今天（流程触发时间） | 流程触发时的当前时间。 |
| 明天（流程触发时间 +1 天） | 流程触发时的当前时间 +1 天。 |
| 后天（流程触发时间 +2 天） | 流程触发时的当前时间 +2 天。 |
| 流程触发人 | 流程触发用户 UserID。 |
| 流程配置者 | 流程创建者 UserID。 |
| 流程触发组织 | 流程触发用户所在组织的 CorpID。 |

## **记忆变量**

记忆变量是 AI 助理可以长期记住的变量信息。详情参考[个性化概述](0083-memory-overview-1.md)。
