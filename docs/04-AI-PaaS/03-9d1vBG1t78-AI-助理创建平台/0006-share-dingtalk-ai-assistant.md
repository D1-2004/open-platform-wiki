# 创建市场 AI 助理

如果你需要将钉钉 AI 助理分享给**任意组织的其他用户**使用，可以参考本文档操作步骤进行创作。

**适用人群**：**所有人** ；**适用范围**：**助理市场创建的 AI 助理**

## **前提条件**

- 钉钉 PC 端版本必须 ≥ 7.6
- 钉钉移动端必须 ≥ 7.6

如果你需要下载最新版本，请点击[这里](https://page.dingtalk.com/wow/z/dingtalk/simple/ddhomedownload#/)进行下载。

## **分享步骤**

1. 登录钉钉客户端，单击右上角**“/AI”** > **选择 AI 助理 ⇋** > **助理市场****。**
2. 在弹出的 AI 助理市场页面，单击右上角**立即创作**。
3. 在我的创作页面，单击右上角**“ + 创作”**，进入创作 AI 助理页面：

   | 创建方式 | 说明 |
   | --- | --- |
   | 从空白创建 | 需自定义助理名称、形象、技能等内容，适合目标明确时使用。 |
   | AI 创建 | 简单描述对助理的要求，AI 自动生成形象、配置。 |
   | 从模板创建 | 选择你期望的模板。 |
4. 配置 AI 助理基本信息：

   | **配置项** | | **描述** |
   | --- | --- | --- |
   | 基本信息 | 助理信息 | - 助理名称：填写助理名称信息。 - 头像与介绍：    - 头像：自定义上传你心仪的 AI 头像。   - 介绍：AI 助理的个性签名，将会展示在个人信息页。 image  助理展示页面，支持查看助理的 AssistantID 和 删除 助理。 |
   | 模型设置 | 不同的大模型提供更加纵深领域的服务，为你解决专业问题提供帮助。 |
   | 角色设定 | 让 AI 助理更好地理解自己的职能和定位，帮助其更稳定和准确地理解用户的需求，是 AI 助理的中枢神经。角色设定除了支持纯文字描述外，还支持引用钉钉平台的数据，包括使用 AI 助理所在环境中的信息数据以及设置好的记忆数据：  - 如果你需要对角色设定有更深入的了解，请参考文档[角色设定](0013-prompt-word-prompt-1.md)。 - 如果你需要在角色设定中插入记忆变量，请参考[个性化](0083-memory-overview-1.md)。 |
   | 欢迎语和开场白 | - 欢迎语：设置一句AI助理与用户首次对话时的欢迎语信息，让用户快速理解你的AI助理的功能和角色。 - 开场白：你可以为AI助理设置开场白，引导用户想AI助理提问题或要求。（非必填）。 |
   | 设置兜底回复 | 兜底回复用于AI助理认为用户的提问超出它的能力范围时的回复文案。  支持 markdown 格式。  如果你需要兜底回复生效，你需要关闭规划的“规划推理强化”能力。 |
5. 添加 AI 能力，配置如下：

   | **配置项** | | **说明** |
   | --- | --- | --- |
   | 技能 | 自定义能力 | 钉钉 AI 的自定义能力，使开发者可以根据自身业务特性，量身定制 AI 助理的行为，详情参考[自定义能力](0024-overview-6.md)。 |
   | 工作流 | 可视化的流程编排，适用于明确、有固定顺序的任务，详情参考[工作流](0036-overview-7.md)。 |
   | 拟人操作 | 模拟人与应用的交互，适用于执行没有开放接口的应用详情参考[拟人操作](https://open.dingtalk.com/document/aipass/development-guide-1)。 |
   | 知识 | | AI 助理能学习知识与用户对话，详情参考[配置知识问答](0074-configure-q-a.md)。 |
   | 个性化 | | 自定义个性化数据为用户提供更加灵活的服务，详情参考[个性化](0083-memory-overview-1.md)。 |
   | 互动方式 | | 提供对话框上方的快捷按钮，支持配置链接、锁定技能、预设提示词。 |
   | 感知触发 | | 感知触发允许 AI 助理在特定的时间点或者当监测到某个特定事件发生时，自动执行相应的操作，详情参考[感知触发](0090-overview-8.md)。 |
   | 规划 | | 提供了为实现特定目标而制定一系列步骤和策略的能力，详情参考[规划](0093-planning-overview-1.md)。 |
   | 安全 | | 可识别用户输入或者大模型生成的敏感词，通过标准话术或敏感词过滤方式降低风险。 |
6. 配置完成后，你可以单击右侧**保存并预览**。你可以测试使用 AI 助理，并且预览调试框，提供了调试能力，你可以单击预览调试框右上方**调试**按钮，进入调试详情页面。AI 助理调试能力详情参考[调试技能调用](0011-debugging-skill-call-1.md)。
7. 在发布助理页面，你可以选择发布范围：

   | **配置项** | **说明** |
   | --- | --- |
   | 通过链接分享给他人使用 | 勾选“通过链接分享给他人使用”，即可通过**链接**或**二维码**​​的方式分享给任意钉钉组织下的任何人使用。 |
   | 同时上架到助理市场 | 勾选“同时上架到助理市场”，则可上架到助理市场。  确认完成后，你需要填写 AI 助理的版本说明信息，然后提交并等待审核，我们一般会在 1 ～ 2 个工作日内完成审核。 |

## **使用步骤**

### **用户使用并添加 AI 助理**

1. 扫描**二维码**或打开**分享链接**。
2. 被分享用户可以在 AI 助理窗口中体验使用，并单击右上角**添加**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1620030171/p778160.png)
3. 添加完成后，可以在钉钉客户端，单击右上角**“/AI”** > **AI 助理 ⇋**，在 AI 助理列表中查看使用。
