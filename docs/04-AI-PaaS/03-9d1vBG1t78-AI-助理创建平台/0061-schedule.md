# 日程

如果你需要使用日程的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## 操作步骤

1. 单击**选择执行动作**，选择**日程 > 创建钉钉日程**。
2. 配置创建钉钉日程：

   | **配置项** | **说明** |
   | --- | --- |
   | 日程标题 | 日程的标题信息。 |
   | 开始时间 | 日程的开始时间。 |
   | 结束时间 | 日程的结束时间。 |
   | 日程参与人 | 日程的参与人。  **[!NOTE]**  - 支持单击 **“⊕”**，设置变量信息，需选择钉钉用户 UserID - 支持单击 “人员标识”，使用选人组件，选择组织内人员。 |
   | 日程地点的名称 | 日程所在地点的名称信息。 |
   | 日程描述 | 对日程的描述信息。 |

## **示例**

以创建周会日程为例，配置执行动作：

| **配置项** | **说明** |
| --- | --- |
| 日程标题 | 输入：周会。 |
| 开始时间 | 选择：2024-06-21 16:00:00。 |
| 结束时间 | 选择：2024-06-21 17:00:00。 |
| 日程参与人 | 你可以单击人员标识，使用选人组件，选择组织内人员。  使用选人组件，快速拉齐所有周会参与者 |
| 日程地点的名称 | 输入：会议室1。  此处为示例，地点可以引用步骤变量，比如与 AI 对话提取 |
| 日程描述 | 输入：本周工作总结。 |
