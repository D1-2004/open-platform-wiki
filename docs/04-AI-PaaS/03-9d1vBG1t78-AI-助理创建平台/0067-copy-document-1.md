# 复制文档

如果你需要使用复制文档的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **操作步骤**

1. 单击**选择执行动作**，选择**钉钉文档 > 复制文档**。
2. 配置复制文档执行动作：

   | **配置项** | **说明** |
   | --- | --- |
   | 复制到 | 选择你需要新增的文档地址。 |
   | 要复制的文档 | 选择你需要复制的文档。 |
   | 复制后的文档标题 | 填写复制后的文档标题。  **[!NOTE]**  支持手动输入或单击 “⊕” 引用动态变量。 |

## **示例**

为复制周报文档为例，配置待办执行动作：

| **配置项** | **说明** |
| --- | --- |
| 复制到 | 选择钉钉文档下“我的文档”。 |
| 要复制的文档 | 选择要复制的文档，例如复制周报的空白文档，详情参考[新增空白文档](0066-new-blank-document-1.md)。 |
| 复制后的文档标题 | 周报文档副本。 |

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6829549171/p815247.png)

此时，一个名为“周报文档副本”就已经复制成功了。
