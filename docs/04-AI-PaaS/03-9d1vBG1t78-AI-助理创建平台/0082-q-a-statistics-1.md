# 问答统计

本文介绍了知识问答问答统计的相关配置。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## 问答统计

AI 助理支持创建者查看其知识的使用情况，你可以直观地看到用户与 AI 助理互动时提出的问题和答案。通过分析交互数据，你可以对知识内容进行优化，确保知识内容传达的准确性。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5504062371/p877754.png)

### **统计操作**

#### **调优**

在问答明细的具体问答的操作栏，单击**调优**，进入问答调优界面，你可以从意图识别和召回、知识检索和处理和生成结果三个阶段进行调优。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5504062371/p877758.png)

#### **提取标问**

对于知识问答具体的内容，你可以将该 QA 对，提取成标准问题。

在问答明细的具体问答的操作栏，单击**提取标问**，进入新建 FAQ 标问：

| **配置项** | **说明** |
| --- | --- |
| 标准问题 | 必填字段，用于描述问题。 |
| 相似问题 | 非必填字段，用于添加与标准问题相似的问法，多个问法通过换行（回车）进行区分。 |
| 答案 | 必填字段，用于填写该问答的答案。 |
| 添加到文档 | 选择，已经创建的 FAQ 知识模板，详情参考[使用标准问答对](0076-using-the-faq-knowledge-template-1.md)。 |
| 分类 | 非必填字段，选择对应的知识分类。 |
