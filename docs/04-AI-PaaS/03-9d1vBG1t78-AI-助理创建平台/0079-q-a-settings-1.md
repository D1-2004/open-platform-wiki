# 问答设置

本文档介绍了知识问答的问答设置相关配置内容。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## 问答设置

| **问答设置** | **说明** |
| --- | --- |
| 技能调用模式 | 提供技能路由干预的能力，你可以选择何时启用智能问答进行回复。帮助你灵活地使用知识。 |
| 使用设置 | - 学习方式：    - 手动学习：若选择手动学习，则知识的学习更新需要创建者通过“知识维护 > 学习知识”手动触发。   - 每天自动学习：若选择每天自动学习，则在知识内容发生更新的第二天系统自动对更新部分的内容进行学习。   - 每周自动学习：若选择每周自动学习，则在知识内容发生更新的本周，系统自动对更新部分的内容进行学习。 - 允许联网搜索进行回答：开启后，当学习知识不足或缺失时，将会结合联网搜索的信息进行回答，优先通过学习的知识进行回答。 - 展示推荐问题：开启后， AI 助理回复中将展示推荐问题列表。 - 展示知识来源：开启后， AI 助理回复中将展示知识来源列表。 - 回答长度（增值能力）：决定知识问答回复的内容长度。 - 回答语言（增值能力）：决定知识问答回复的语言格式。 - 问答权限：    - 以助理使用权限判断：该方式不对使用成员是否拥有文档权限进行判断，均可通过知识问答获取答案，请注意防范数据泄露风险。   - 以知识文档权限判断：该方式仅从使用成员拥有“可查看”以上权限的文档进行答案召回，群内使用助理需要注意因群内成员文档权限差异导致的数据泄露风险。 |
| 参数设置 | - 构建知识图谱（增值能力）：构建已学知识的图谱，实现知识的通篇回答；学习知识中的图文，强化图文输出能力。 - 给予上下文多轮对话（增值能力）：每次对话是否参考上下文进行回答。 - 知识切片设置（增值能力）：    - 知识切片召回数量：从学习的知识中输入给大模型的最大切片段落数，数值越大输入的内容越多，但受大模型 token 大小限制，超出部分低匹配度的切片段落将不会输入到大模型。   - 切片匹配度阈值：根据设置的匹配度选取切片段落输入给大模型，低于设置匹配度的内容将不会被召回。 |
