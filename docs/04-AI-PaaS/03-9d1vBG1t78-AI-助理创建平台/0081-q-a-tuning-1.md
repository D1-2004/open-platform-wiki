# 问答调优

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **概述**

问答调试是钉钉提供的一套推理可视化与推理过程可调优的工具。帮助 AI 助理管理者更精准的调试问答效果。用户可通过调试工具了解到问答推理的步骤，并查看每个步骤的输出的结果是否符合预期，若不符合预期则通过对应的优化手段，对涉及内容或配置进行干预。

### **问答过程白盒化**

展示知识推理每个阶段的执行步骤及结果，并支持对每个步骤中涉及的调试项进行干预，以实现用户的问答预期效果。

### **优化问答效果**

对知识推理中每个步骤涉及的调优项进行干预，包括：知识、术语、场景的匹配，切片提前、问答参数等配置项。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3670883371/p885667.png)

## **适用场景**

问答场景解决问答中复杂或特定的查询要求，通过配置问答场景匹配用户意图，并指定查询的知识，提升回答准确度。

## **使用方式**

### **功能入口**

问答调优提供了两个入口，分别是：

| **入口方式** | **说明** |
| --- | --- |
| 预览调试台 | 助理管理员在发布前，在预览调试台验证问答效果并调优。  image |
| 知识管理页面 > 问答统计 | 助理管理员可以在知识管理页面 > 问答统计页面，点击调优。  image |

### **问答调优**

#### **识别问题**

用于识别用户的问题，以及匹配的问答场景和术语库。

| **意图识别和召回** | **说明** |
| --- | --- |
| 问答场景匹配 | 通过对用意图的理解匹配问答场景，若匹配到问答场景，则知识将从问答场景指定的知识范围进行召回。若未匹配到问答场景，则从该助理所有学习的知识中进行召回，同时可从当前环节跳转到问答场景中新增或修改问答场景。  image  问答场景参考[问答场景](0080-q-a-scene-1.md)内容。 |
| 术语库匹配 | 当用户的意图里包含了大模型无法理解的行业术语、业务含义、企业内部的黑话，可通过维护术语库维护，此环节展品用户意图中匹配到的术语，若未匹配到或术语确实，则通过“维护术语库”快捷入口进行维护。  image  术语库参考[配置知识问答](0074-configure-q-a.md)内容。 |
| 意图改写 | 当用户开启多轮对话，则模型会根据上下文内容改写意图，如果不希望上下文对用户的意图进行干扰，可关闭多轮对话，关闭后模型仅根据用户当前输入的内容进行回答。  image |

#### **检索知识**

用于展示基于用户问题检索到的相关知识，以及知识的切片信息。

| **知识检索和处理** | **说明** |
| --- | --- |
| 知识检索参数 | 展示当前助理知识检索参数，系统默认的知识检索参数为“知识切片召回梳理：6”；“切片匹配度阈值：0.3”，用户可通过该步骤查看知识检索参数，并对齐进行调整，知识检索参数的含义如下：   - 知识切片召回梳理：从学习的知识中输入给大模型的最大切片段落数，数值越大输入的内容越多，但受大模型token大小限制，超出部分低匹配度的切片段落将不会输入到大模型。 - 切片匹配度阈值：根据设置的匹配度选取切片段落输入给大模型，低于设置匹配度的内容将不会被召回。   image |
| 检索到的文档 | 基于用户问题检索到的知识来源，此处的知识来源包含用户上传的知识、系统构建的图谱知识，用户的记忆知识等，用户可通过添加知识的方式补充更多该问答涉及的知识。  image |
| 相关知识 | 查看该问题涉及的知识内容，检索该内容是否包含问题的正确答案，若缺失知识内容，则可通过添加知识或调整知识检索参数的方式进行调整。  image |

#### **回答结果**

为大模型基于用户问题以及检索到的相关知识，最终输出的答案结果，若结果不符合预期，可通过“修改问答设置”调整问答相关参数，包含使用设置、参数设置等配置信息。
