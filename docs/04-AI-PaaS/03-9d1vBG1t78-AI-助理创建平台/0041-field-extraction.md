# 字段提取

如果你需要使用待办的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **操作步骤**

1. 单击**选择执行动作**，选择 **AI 能力 > 字段提取**。
2. 配置字段提取内容：

   | **配置项** | | **说明** |
   | --- | --- | --- |
   | 用到的 AI 模型 | | 选择该执行动作用到的底层大模型，可选模型包括：  - 通义千问-plus - 通义千问-max - 通义法睿 - MiniMax abab6.5s-245k - 月之暗面128K - ChatGLM4 - 零一万物-large - 猎户星空 |
   | 待提取的文本 | | 输入一段文本内容，AI将从这段内容中提取出关键的字段信息。  **例如：**  你可以输入或引用一句来自用户的反馈：“你们家的防晒霜太油腻了”，然后在下方要提取的字段中添加“满意程度”、“产品名称”字段，AI 将会提取出这句话的满意程度、提到的产品名称。  你可以手动输入内容，也可以单击“⊕”，引用变量进行动态传参，详情参考[变量概述](0054-variable-overview-1.md)。 |
   | 要提取的字段 | 固定参数 | 预期返回固定参数，你可以在下方固定参数中填写你期望 AI 提取的字段。  需要填写的字段包括参数名称、参数类型、默认值、参数描述。  参数类型包括：文本、数字、是否。 |
   | JSON结构体 | 预期获取 JSON 结构的数据，例如：   ``` { "title":"标题", "content":"内容" } ``` |

## **示例**

以查询商品销售信息为例，配置字段提取文档内容：

| **配置项** | | **说明** |
| --- | --- | --- |
| 用到的 AI 模型 | | 选择：通义千问-plus。 |
| 待提取的文本 | | 查询杭州门店商品ID12345的销售信息。 |
| 要提取的字段 | 固定参数 | 参数一：   - 参数名称：门店 - 参数类型：文本 - 描述：从用户输入的信息中获取门店地址 |
| 参数二：   - 参数名称：商品ID - 参数类型：数字 - 描述：从用户的输入信息中获取商品 ID |

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0351361271/p823822.png)

设置完成后，你就可以在后续节点中选择「门店」和「商品 ID」字段了。
