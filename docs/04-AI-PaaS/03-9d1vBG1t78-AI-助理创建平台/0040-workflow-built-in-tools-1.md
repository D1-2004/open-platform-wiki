# 内置工具

本文将详细描述在内置工具中如何使用**条件**、**HTTP**和**获取指定的日期时间**的执行动作。

## **适用人群**

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **准备工作**

正式使用前，需要提前了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

## **条件**

### **操作步骤**

1. 单击**选择执行动作**，选择**内置工具 > 条件**。
2. 配置条件内容：

   > **[!NOTE]**
   >
   > 支持字符串类型多条件的并且和或者逻辑，并且逻辑需要满足所有的设定条件流程才会向下执行，或者逻辑只需要满足条件其一就可以向下执行。

   | **配置项** | | **说明** |
   | --- | --- | --- |
   | 条件 | 请选择变量 | 选择一个需要设定条件的变量。变量详情参考[变量](0054-variable-overview-1.md)。  变量仅支持引用字符串类型和时间类型字段。  记忆变量目前均为字符串类型字段。 |
   | 选择条件 | 选择你需要的条件：  - 对于字符串，目前支持的条件有： - 包含 - 不包含 - 等于 - 不等于 - 为空 - 不为空 - 包含于 - 以...开头 - 不以...开头 - 以...结尾 - 不以...结尾 - 对于系统变量中的时间类型，目前支持的条件有： - 早于 - 晚于 - 不早于 - 不晚于 - 等于 - 不等于 - 为空 - 不为空 |
   | 请输入 | 填写你需要满足的条件信息。 |

### **示例**

如果你仅需要对客服场景的情形做进一步的处理，因此需要对“是否为客服场景”做判断：

1. 执行动作选择 **AI 能力** > **向AI提问**，配置如下：

   | **配置项** | **说明** |
   | --- | --- |
   | 问题 | 输入：  现在开始，我输入一句话，你就需要帮我解析这句话的内容，从而提取出5个关键的信息，分别是：  1.是否为客服场景。即这句话是否是顾客对客服人员说的话，比如投诉、提出建议、吐槽、反馈、夸赞、咨询某个产品或服务。你只需要回答是或否。  2.现状问题。即这句话描述了什么问题，请指出这句话是对哪个问题感到不满，推测出现状的问题是什么。如果这句话是夸赞的话，就回答无。  3.改进的方向。即这句话的意图是想以后要怎么改进，请推测出改进的方向计划。如果这句话是夸赞的话，就回答继续保持某个方面。  输入的话：1. 对话输入原文  1. 对话输入原文为步骤1的输入变量，需要单击右上角 “⊕” 引用。 |
   | 设置AI的回答格式 | 选择JSON结构体  格式定义：  {  "是否为客服场景":"否",  "现状问题":"现状问题",  "改进的方向":"改进的方向"  } |

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4865329171/p813741.png)
2. 配置条件执行动作：

   | **配置项** | | **说明** |
   | --- | --- | --- |
   | 条件 | 请选择变量 | 选择：2. 是否为客服场景 |
   | 选择条件 | 选择条件：等于 |
   | 请输入 | 是 |

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4865329171/p813742.png)

   至此，工作流对客服场景的判断就完成了，后续可以对客服场景的需求做更丰富的功能。

## **HTTP**

### **操作步骤**

1. 单击**选择执行动作**，选择**发起 HTTP 请求**。
2. 配置 HTTP 请求内容：

   | **配置项** | | **是否必填** | **说明** |
   | --- | --- | --- | --- |
   | 请求类型 | | 是 | 请求包括：  - **GET**：获取服务器数据 - **PUT**：修改服务器的数据 - **POST**：向服务器提交数据（例如提交表单或者上传文件） - **PATCH**：部分修改服务器的数据 - **DELETE**：删除服务器的数据 - **OPTIONS**：获取服务器支持的请求类型 |
   | 入参 | 请求URL | 是 | 填写请求路径。 |
   | 请求参数 | 否 | 填写请求的 query 参数，格式：Key-Value。 |
   | 请求 Header | 否 | 填写请求的 Header 参数，格式：Key-Value。 |
   | 请求body | 否 | 填写请求体内容。 |
   | API Secret | 否 | 填写签名密钥，可自定义。 |
   | 出参 | Text  配置的出参内容，即可在后续节点选择使用。 | 否 | 期望返回的信息为纯文本。   ``` 这是一段文本内容 ``` |
   | JSON  配置的出参内容，即可在后续节点选择使用。 | 否 | 期望返回的信息为 JSON 结构，示例如下：   ``` { "title":"标题", "content":"内容" } ``` |
   | None | 否 | 期望无返回内容。 |

## **获取指定的日期时间**

### **操作步骤**

1. 单击**选择执行动作**，选择**内置工具 > 获取指定的日期时间**。
2. 配置获取指定的日期时间：

   | **配置项** | **说明** |
   | --- | --- |
   | 原日期时间 | 选择一个日期。 |
   | 加减处理 | 支持加减逻辑。  **[!NOTE]**  支持单击 **“⊕”，**进行动态引入 “+” 或 “-”，动态引入的内容必须  是“+” 或 “-”之一。否则出现执行错误的错误提示。 |
   | 天 | 在原日期基础上增加/减少的天数。 |
   | 小时 | 在原日期基础上增加/减少的小时数。 |
   | 分钟 | 在原日期基础上增加/减少的分钟数。 |
   | 秒 | 在原日期基础上增加/减少的秒数。 |

### **示例**

以获取流程触发的某天之后第二天的日期时间为例：

| **配置项** | **说明** |
| --- | --- |
| 原日期时间引用 | 支持单击 **“⊕”**，选择系统变量 > 今天（流程触发时间）。 |
| 加减处理 | 选择 “+”。 |
| 天 | 填写：1。 |

此时，获取某天之后第二天的日期时间就已经配置完成。

## **常见问题**

### **入参中** API Secret 有什么作用？怎么使用？

答：如果你请求的系统需要对请求进行验签，那么当你填写了 apiSecret 时，你的系统收到的 HTTP 请求 Header 中将包含签名相关 Header：

- x-ddpaas-signature-timestamp：<签名时时间戳>
- x-ddpaas-signature：<签名串>

其中 <签名串> = calcSignature(apiSecret, <签名时时间戳>)，apiSecret 是注册时指定的签名密钥。

你请求的系统应使用如下方法计算签名并验证签名串是否正确，以防未授权的调用：

```
public static String calcSignature(String apiSecret, long ts) {
    try {
        Mac mac = Mac.getInstance("HmacSHA256");
        SecretKeySpec key = new SecretKeySpec(apiSecret.getBytes(), "HmacSHA256");
        mac.init(key);
        return Base64.getEncoder()
            .encodeToString(mac.doFinal(Long.toString(ts).getBytes()));
    } catch (NoSuchAlgorithmException | InvalidKeyException e) {
        log.error("sign api secret failed", e);
    }
}
```
