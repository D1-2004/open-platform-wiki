# 让 AI 助理更容易学会知识

如果你觉得 AI 助理回答没有符合你的预期，那可能是因为你对知识学习还不够了解，你可以参考本文内容，带你了解如何更好让 AI 进行知识学习。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **了解“知识”的运行原理**

懂得 AI 助理 “知识”学习背后的原理，能够帮助你更好的提升运用“知识”学习：

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0075329171/p804017.png)

“知识”的运行主要涉及四个步骤分别如下：

### **1. 内容切片**

对用户提供的知识内容，模型会对将每篇文档拆分成多个片段，每个片段均有3个部分：

1. 文章标题：本篇内容的标题

2. 段落标题：当前段落所属的标题及其祖先标题

3. 内容：可以是正文文字、表格、代码块等内容

> **[!NOTE]**
>
> 每个片段拼接后的长度不能超过 512 字符。

在学习链路中，模型会将千万级的学习内容拆分成亿万级别的片段，然后通过存储在“库”中。

#### **片段一**

```
钉三多集团员工福利
一、福利
1. 补贴
在补贴方面，我们提供了丰富多样的补贴项目...
```

#### **片段二**

```
钉三多集团员工福利
二、假期
1. 节假日
在节假日，我们根据国家规定和传统习俗...
```

#### **片段三**

```
钉三多集团员工福利
二、假期
2. 年假
年假是员工休息和放松的重要保障...
```

### **2.** 相似度计算

当进入问答链路之后，模型会根据用户提出的问题，在以亿计的文档片段中找到几百个相似的片段，即召回。然后通过相似度计算，分别计算问题与每一个片段的语义相似度，并根据相似度从高到低排序。

例如，当用户输入：**钉三多集团有什么假期福利？**

模型返回相似片段并排序：

#### **片段三 相似度：95%**

```
钉三多集团员工福利
二、假期
2. 年假
年假是员工休息和放松的重要保障...
```

#### **片段二 相似度：60%**

```
钉三多集团员工福利
二、假期
1. 节假日
在节假日，我们根据国家规定和传统习俗...
```

### **3.** 权限控制与数据隔离

创建 AI 助理时，模型会对创建者的知识来源的权限范围进行识别，会基于该内容数据中用户有权限的部分进行学习。

- 使用 AI 助理时，所有拥有 AI 助理使用权限的用户都可以针对该AI助理的全部知识内容进行智能问答。
- 通过数据隔离保障用户的数据安全，上传的知识不会用于模型训练，用户与用户之间的数据是相互隔离不可见的。

### **4.** 生成答案

最终模型会选出语义度最高的1-10个片段同问题一并送入大语言模型（LLM），由大语言模型最终在1-10个片中进行甄别与整合，向用户输出最终答案。

#### **第一步** 模型选出相似度最高的片段

```
钉三多集团员工福利
二、假期
2. 年假
年假是员工休息和放松的重要保障...
```

#### **第二步** 模型生成答案

```
钉三多集团的假期福利主要包括年假，公司给予员工的年假天数不仅完全符合国家规定标准，还会根据员工的工作年限和表现给予额外的假期奖励。鼓励员工合理安排年假时间，用于旅游度假或与家人相聚，充分休息和调整自己，以更加饱满的状态投入到工作中。
```

## **知识撰写的普遍原则**

> **[!NOTE]**
>
> AI 不是万能的，如果你让 AI 学习的内容，自己看起来都不好理解，那么对于 AI 来说也是有难度的。

1. 清晰的结构：确保文章有清晰的结构，包括引言、主体和结论。
2. 使用简单语言：尽量使用简单、直接的语言。避免使用过于复杂或模糊不清的表达。
3. 明确的概念定义：在提及专业术语或概念时，给出明确的定义，避免歧义和多义性。
4. 逻辑连贯性：确保文章中的论述逻辑清晰，因果关系明确。
5. 具体举例：适当给出示例来说明抽象的概念或理论。
6. 使用清晰的指代：确保代词明确地指向特定的名词，避免指代不清产生混淆。
7. 有序列表和分类：如适用，使用有序列表或分类的方式组织信息帮助AI提取和组织关键信息。
8. 重复强调：对于文章的主题或重点，适当进行重复强调，有助于 AI 捕捉和加深理解。

## **提升 AI 学习效率的编写技巧**

### **1.** 题文对应，你的标题要与正文内容强相关

在相似度计算的逻辑里，文章标题占有较高的权重。如果某个片段所属的文章标题和用户的提问很吻合，就会提高这个片段的排序名次，从而更容易被选为最终输入大模型的 1-10 个片段。如果此时正文内容和文章标题不相关，就会造成回答不准确，答非所问的情况。

### **2. 设置段落标题并控制段落长度**

**A.** 不要将不同的知识点混在同一个段落中，不同的知识点需要使用段落标题来区分，保证在内容切片的时候每个片段的主题是明确的。

**B.** 由于在进行内容切分的过程中，每一个段落需要在 512 个字符以内，因而每一个段落标题下的正文内容最好在 500 字以内。这样可以避免因为段落内容过长，一个主题的段落被切割成了多个片段，这样会导致最终输出的答案不够全面。

### 3. 避免使用大模型现阶段不擅长理解的格式描述重要的信息

在知识学习中虽然我们已经可以支持识别例如表格、ppt 等多种格式，但是识别效果仍在进一步提升中。特别是图片、脑图、视视频等文件还不支持。所以重要信息的表达我们还是推荐使用普通文本进行描述，推荐使用钉钉文档。

> 这些局限性会随着钉钉AI能力的的不断迭代逐渐消失。
