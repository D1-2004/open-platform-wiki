# 内容审查

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **概述**

内容审查确保 AI 应用交互过程中的内容安全性和合规性，对大模型输出和输入词汇进行监控，有效屏蔽不当或者敏感信息。

## **操作步骤**

1. 了解[创建组织内使用的 AI 助理](0005-create-a-dingtalk-ai-assistant-1.md)，进入 AI 助理创建页面。
2. 单击**安全** > **管理**，进入内容审查配置页面。
3. 配置审查规则：

   | **配置项** | | 特点 | **说明** |
   | --- | --- | --- | --- |
   | 规则名称 | | —— | 填写规则名称 |
   | 审查方式 | 关键词匹配 | - 匹配效率高 - 匹配确定性高 - 设置过程操作简单，但是枚举全部敏感词成本高 | - 每行一个关键词，最多支持 100 行 - 一个关键词最多支持 100 个字符。 |
   | 正则表达式 | - 匹配效率高 - 匹配确定性高 - 设置过程操作有少量门槛，需要有正则表达式配置基础 | 正则表达式是一种用于文本匹配的模式，可以用来在字符串中查找特定内容。例如：  - 匹配文案是否有手机号码：^1[3-9]\d{9}$ - 匹配所有含有敏感词“退款”的句子：.\*?退款.\*? |
   | 意图识别 | - 匹配效率相对慢 - 匹配确定性相对低 - 通过自然语言告诉大模型你需要识别的敏感内容，设置门槛低，枚举 | 大模型会自动检测是否有符合要求的内容，请清晰描述内容，例如：  - 判断是否有退款相关的内容 - 判断是否包含公司经营数据 可通过配置管控严格程度决定匹配精确性。数值越大，匹配度越精确，但是可能带来漏判；数值越小越容易触发管控，但是可能带来更多误判。 |
   | 审查范围 | 检查用户输入内容，命中规则后 | —— | 输入检测到关键词时 AI 输出的内容，支持 Markdown 格式 |
   | 检查 AI 助理输出内容，命中规则后 | —— | - 回复固定文案（支持Markdown格式） - 对敏感内容打\*处理 |

   配置完成后，单击**保存**。
