# 公式编辑概述

**适用人群**：**开发者** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **什么是公式编辑**

**公式编辑**是为用户提供一个安全、可控的环境来运行Python表达式或代码片段，以完成复杂的参数转换。用户可以方便地在表达式模式和代码模式之间切换。表达式模式主要用于计算数学表达式、执行时间函数和应用格式映射，而代码模式则允许执行更复杂的Python代码。

### **表达式（公式模式）**

表达式中内置一系列功能函数，涵盖了时间计算、数学运算和数据格式转换等常用任务，用户无需额外编写复杂代码即可实现这些功能。

### **代码模式**

代码模式中内置了例如`numpy`、`pandas`等强大的数据分析库，以及`datetime`和`json`等标准库，以便用户能够直接操作数组、处理表格数据、进行日期时间操作和解析JSON格式的数据。

## **如何打开公式编辑页面**

在工作流中，大多数执行动作输入框都存在 “⊕”，此时你需要：单击 **“⊕”** > **使用公式编辑**。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2965329171/p813857.png)

> 部分输入框由于其特定性质或预设配置不提供“使用公式编辑”的选项。

## **表达式模式/公式模式（Expression Mode）**

### **适用场景**

当你需要快速计算数学表达式、处理日期时间格式或应用简单的数据转换时，表达式模式是理想的选择。

### **功能特点**

内置函数涵盖了广泛的需求，如基础数学运算、字符串操作、时间格式化等，用户仅需通过点选或输入函数名即可调用，无需关注底层实现细节。

### **使用说明**

- 在该模式下，直接输入你的表达式，如数学计算`(3 + 4) * 2`，14 将作为该输入框的参数在工作流运行时填入。或调用内置函数进行操作，如时间格式转换`DATEFORMATe('2024-01-03', ''%Y年%m月%d日)`，这将使得“2024年01月03日”作为参数填入。
- 在“变量列表”列，可以点击来自工作流上游节点的出参作为变量输入，例如：

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2965329171/p813853.png)
- 如果你对 Python 熟悉，也可以按照`eval`支持的语法进行输入。

## **代码模式（Code Mode）**

### 适用场景

对于需要执行更复杂逻辑、利用高级库功能或处理结构化数据的任务，代码模式提供了更广阔的舞台。适合有一定编程基础的用户。

### 功能特点

不仅包含表达式模式的所有功能，还额外支持导入外部库、定义变量、循环控制、条件判断等编程结构，以及直接操作 DataFrame 等复杂数据结构。

### **使用说明**

在此模式下，你需要像在常规 Python 环境中编写代码。其中`main`函数是脚本入口，你**必须保留**才可以运行代码。并且该函数的返回值将作为参数填入输入字段，例如：输出 “你好钉钉，Hello DingTalk！”：

```
def main():
  return "你好钉钉，Hello DingTalk！"
```

## **注意事项**

- 代码模式和公式模式的内容不会同时执行，只能二选一。
- 使用公式编辑确认后将覆盖原有的文本输入内容。

  ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2965329171/p813859.png)

  - 公式编辑中的脚本最长运行时间为3秒，超过时限将返回空值。

## **安全性与可控性**

为确保系统安全及数据的完整性，公式编辑环境实施了严格的安全策略：

- **沙箱执行**：所有代码都在隔离的沙箱环境中执行，每次执行将重置环境，你无法保存持久化数据。
- **资源限制**：代码单次运行环境最大内存 192 MB，最长运行时间 3 秒。
- **白名单机制**：仅允许使用预批准的函数和库，阻止潜在的危险操作，如文件读写、网络请求等。

## **公式编辑优势**

### 安全性与沙盒环境

**公式编辑**的核心特性之一是其构建于安全的沙盒环境中。这意味着你编写的代码将在一个隔离的环境中执行，每次运行都将重置环境，保证工作流运行的安全性和稳定性。这一设计为用户提供了既强大又安全的计算环境，也意味着你无法在公式编辑中使用网络。（例如发送HTTP请求）。

### **实时反馈与错误提示**

**公式编辑**具备实时反馈机制。在用户输入代码的过程中，会即时分析语法，提供自动补全建议，保存时校验语法并对潜在的错误进行高亮提示。可以帮助你快速定位并修正错误。

### **多样化的数据支持**

无论是处理数值、文本还是日期时间等不同类型的数据，**公式编辑**不仅支持基础的数据类型操作，还针对特定场景提供了丰富的 API 接口，如日期时间的格式化与解析、字符串的正则匹配与替换、列表与字典的高级操作等。这使得用户能够轻松应对数据预处理、清洗及转换等多种任务，满足不同领域和场景的需求。此外，结果输出格式灵活，支持 JSON、CSV 等多种格式导出，便于与其他系统或工具集成。

### **持续更新与扩展性**

公式编辑底层基于`Python3.10`，拥有强大的社区支持，确保了技术的现代性和前瞻性。随着`Python`生态的不断发展壮大，**公式编辑**也将持续集成最新的库和功能，以适应日益复杂的数据处理需求。用户可以期待定期的功能更新和性能优化，使得公式编辑成为一个随技术演进而成长的工具。

### **灵活的上下文传递与变量管理**

理解数据处理任务往往需要对上下文信息的精准把握。**公式编辑**允许用户定义和引用外部变量，这些变量可以是来自上游步骤的数据或者预设的常量。

## **应用场景**

### **数据预处理与清洗**

原始数据往往需要经过一系列的预处理才能用于模型训练或业务洞察。公式编辑以其灵活的数据处理能力，成为数据预处理阶段的强大辅助工具。用户可以利用其内置的库和函数快速完成缺失值填充、异常值检测与处理、数据类型转换、字符串清理等基础任务。同时，借助于 Pandas 库，复杂的数据重塑、聚合分析、分组统计等操作也能轻松实现，有效提升数据质量，为后续分析奠定坚实基础。

### **自定义计算与转换逻辑**

面对特定领域的复杂计算需求，如 API 接口中的签名加密、物理学中的物理量转换、或是电商领域的个性化推荐算法，公式编辑提供了高度可定制的计算环境。用户可以通过编写自定义函数和逻辑，实现业务规则的具体化，确保数据处理逻辑的精确执行。

### **复杂参数映射的深入应用**

在高级数据分析和系统集成项目中，复杂参数映射不仅是数据字段间一对一的简单对应，它还涉及到多层逻辑判断、数据转换算法的应用，甚至需要根据业务规则动态调整映射策略。公式编辑通过其强大的表达式和代码执行环境，为这类复杂需求提供了丰富的解决方案。

### **动态映射规则**

当数据源的结构频繁变动或业务需求多变时，静态映射规则可能难以满足要求。公式编辑允许用户编写条件语句（如if-else逻辑），根据输入数据的具体情况动态决定映射路径。例如，根据产品类别自动选择不同的价格计算公式，或根据用户行为历史动态调整推荐算法的参数。

### **高级数据转换**

复杂参数映射还体现在对数据进行深度加工和转换的能力上。公式编辑集成的库，如 Pandas，使得用户能执行列级别的数据操作，如数据分桶、独热编码、类别特征编码等，这些在机器学习预处理阶段尤为关键。此外，利用 Python 强大的数学和统计函数，可以直接在映射过程中实现复杂的数值计算和数据标准化，为模型训练提供高质量的数据输入。
