# 联网搜索网页

如果你需要使用联网搜索网页的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **操作步骤**

1. 单击**选择执行动作**，选择**资讯搜索** > **联网搜索网页**。

   1. 配置内容：

      | **配置项** | **说明** |
      | --- | --- |
      | 搜索关键词 | 输入想要搜索的关键词。 |

      > **[!NOTE]**
      >
      > 搜索结果不会在该页面显示，请继续向下添加新步骤，并在后续步骤中引用搜索结果。

## **示例**

以搜索小猫网页为例，配置内容如下：

1. 联网搜索网页：

   | **配置项** | **说明** |
   | --- | --- |
   | 关键词 | 输入：小猫。 |
2. 此时，你可以在后续步骤引用搜索到的网页列表。如需在卡片中输出每个网页信息，推荐选择AI助理回复互动卡片 > 从模板生成 > 图文列表。

   | **配置项** | | **说明** |
   | --- | --- | --- |
   | 生成方式 | | 选择：从模板生成 |
   | 选择模板 | | 选择：图文列表 |
   | 卡片字段内容 | 图文列表 | 选择：动态条数。其余变量配置如下：  - 文章标题：引用“网页标题” - 文章链接：引用“网页链接” - 描述（选填）：引用“网页描述” - 标签（选填）：引用“更新时间” |

此时，你已完成联网搜索网页，并在卡片中展示。
