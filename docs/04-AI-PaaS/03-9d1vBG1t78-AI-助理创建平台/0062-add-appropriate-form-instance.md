# 新增宜搭表单实例

用于在宜搭表单中新增一行数据（暂不支持流程表单），在使用新增宜搭表单实例前，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **操作步骤**

1. 在工作流搭建页面，单击**选择执行动作** > **钉钉协作** > **宜搭**，选择新增宜搭表单实例。
2. 配置新增表单实例执行动作：

   | **配置项** | | **说明** |
   | --- | --- | --- |
   | 应用表单信息 | 应用编码 | 打开你的宜搭应用，单击**应用设置** > **部署运营**，复制获取应用编码和应用密钥。  image |
   | 应用密钥 |
   | 宜搭表单 | 填写应用信息完成后，单击**刷新**按钮。即可选择对应宜搭表单。 |
   | 表单字段内容 | | 填写宜搭表单中的字段内容。  当前仅支持日期、数值、下拉复选、下拉单选、单行文本、多行文本、人员这几种类型的字段。 |

## **示例**

| **功能说明** | **功能搭建预览** |
| --- | --- |
| 一家全国连锁的零售企业，需要从各个门店收集关于新上架商品的顾客反馈。通过 AI 助理工作流，企业可以自动收集各门店提交的反馈信息到宜搭表单，并在后续进行 AI 多维度分析，生成报告供管理层审阅。 | 1. 在 AI 助理工作流中，设置提取用户对话中的反馈内容。  image 2. **添加新增宜搭表单实例执行动作，将反馈内容记录到宜搭表单。**  image |
