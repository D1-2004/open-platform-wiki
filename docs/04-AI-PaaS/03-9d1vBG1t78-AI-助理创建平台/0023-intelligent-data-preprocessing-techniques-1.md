# 数据预处理技巧

如果你需要更好得使用智能问数的能力，本文档介绍了数据集的配置和原始数据的加工的使用技巧。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **数据集配置**

1. 数据集的名称及描述贴合业务，最好为中文。
2. 不同数据集的描述要有所区分，以帮助大模型进行表的路由。
3. 数据集的字段名称及描述贴合业务，描述里面备注清楚业务含义（如同义词，业务含义等），最好把示例值也展示出来，比如名称“类目”描述“也可以叫类型、分类，值不同服装的类目，包括女装、男装、童装”。
4. 关键维度信息的选取和勾选，用于帮助AI根据用户提问进行优先匹配。

## **原始数据加工**

### **表格数据/数据库数据（数据相关）**

1. 字段类型与数据本身类型尽可能保持一致，如数值定位为字符串类型。
2. 减少脏数据，如空格，空值，非一致类型等。
3. 减少模型推理，字段提前加工，如涉及到总价 = 单价 \* 数据，如果直接有总价字段更明确。
4. 减少有歧义的字段或值，如枚举项的多值问题。

### **表格数据（格式相关）**

1. Excel 文件默认第一行为表头，表头要见名知意，表头长度为 30 个字符，不能为数字开头，尽量不使用特殊符号（注：当表头为空时，当前列所有数据都会被丢失）。
2. Excel 文件默认从第二行往下为表数据，每一列表数据的类型建议一致，如表头为【价格】数据列，建议都是数值型，不要出现字符串，否则当前类会被判断为字符串（注：当表数据为空时，当前数据被替换为NULL）。
3. Excel 文件数据类型为日期类型时，建议采用 Excel 提供的标准日期类型,如 2024-07-01 和 20240701，减少特殊日期类型的使用，如 7.1.2024、0701-2024等。
4. Excel 文件优先选择 XLSX 格式，解析兼容性更好；针对 xls 格式的文件，EXCEL 编辑器版本不低于 2007。
5. Excel 文件避免使用「合并单元格」、「公式计算」、「升序降序」等功能。
