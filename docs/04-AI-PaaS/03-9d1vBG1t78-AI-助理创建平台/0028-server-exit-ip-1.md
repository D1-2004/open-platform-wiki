# 服务器出口IP

本文档提供了自定义能力当前使用的出口IP地址列表，请根据这些IP地址配置您的防火墙或安全设置，以保证通信畅通无阻。

**适用人群**：**开发者** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **出口 IP 列表**

当使用 HTTP 协议开发自定义能力时，如果希望仅允许特定IP发起的请求通过您的服务器，可以在您的网络设备上为下述列出的所有IP地址创建允许规则，钉钉 AI 助理的服务器出口 IP 如下列表所示：

```
47.92.55.179
47.92.238.191
39.100.39.123
```
