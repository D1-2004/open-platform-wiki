# 图片解读

图片解读可以帮助你让大模型按照一定要求理解图片，并且该能力提供了图片分类模型的强化方式，帮助你在特定场景下进行图片的专业识别。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **应用场景**

| **直接用 prompt 提示大模型如何识别图片** | **特定的图片分类模型** |
| --- | --- |
| image | image |

## **特点**

图片解读图片分类的多模态模型加强方式，可以更容易被应用于业务生产中。

平时工作生活中，有很多问题都可以通过图片分类的方式来解决，例如：

- **商品图片识别**：对图片按照商品维度进行的分类识别。
- **人员着装识别：**对衣着类别的分类识别。
- **店铺巡检**：对店铺照片符合标准和不符合标准的情况分成不同类别进行识别。

## **前提条件**

进入 AI 助理创建页面，详情参考[创建组织内使用的 AI 助理](0005-create-a-dingtalk-ai-assistant-1.md)。

## **场景一：使用通用模型 + prompt 对图片进行分析**

1. 在 AI 助理创建页面，单击**技能** > **图片解读编辑标识**，进入图片理解设置页面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1039825371/p895266.png)
2. 选择“通义千问 VL 模型”，按照业务场景设置提示词。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1039825371/p895265.png)

## **场景二：对模型进行图片分类强化**

1. 在 AI 助理创建页面，单击**技能** > **图片解读编辑标识**，进入图片理解设置页面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1039825371/p895266.png)
2. 在图片理解设置页面，单击**强化模型**，进入强化专属模型配置页面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1039825371/p895270.png)
3. 单击**添加模型**，配置专属图片模型：

   | **配置项** | **说明** |
   | --- | --- |
   | 模型名称 | 填写自己的模型名称。 |
   | 模型介绍 | 主要用于在选择模型时，让选择人员了解模型的背景和能力。 |
   | 强化方向 | 选择**图片分类**方向。 |
   | 分类失败时提示文案 | 当模型在强化后，遇到了无法进行分类的图片时，给予的默认文案。 |
4. 配置强化专属模型：

   | **配置方式** | **说明** |
   | --- | --- |
   | 手动操作 | 1. 手动添加分类  image 2. 在对应分类下上传图片。  image  也可以直接上传到「全部」类别下然后批量标注。 3. 上传完成后，大模型将自动学习上传图片 |
   | 按照模板批量上传 | 1. 下载模板示例  image 2. 根据模板示例，将图片打包成 .zip 格式文件，然后上传。  image  image 3. 上传完成后，系统会根据图片自动打上分类。  image |
5. 配置完成后，你就可以使用强化的专属模型了：

   | **使用范围** | **说明** |
   | --- | --- |
   | 图片解读技能 | 在图片理解设置页面，单击**刷新列表**，选择配置完成的专属模型。  image |
   | 工作流 | 1. 进入 AI 助理工作流配置页面，详情参考[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)。 2. 选择 **AI 能力** - **图片解读**执行动作，可以选用配置完成的专属模型。  image |

## **场景三：图片目标检测强化**

1. 在 AI 助理创建页面，单击**技能** > **图片解读编辑标识**，进入图片理解设置页面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1039825371/p895266.png)
2. 在图片理解设置页面，单击**强化模型**，进入强化专属模型配置页面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1039825371/p895270.png)
3. 单击**添加模型**，配置专属图片模型：

   | **配置项** | **说明** |
   | --- | --- |
   | 模型名称 | 填写自己的模型名称。 |
   | 模型介绍 | 主要用于在选择模型时，让选择人员了解模型的背景和能力。 |
   | 强化方向 | 选择**图片检测**方向。 |
   | 相似范围 | - 橙色段：识别为疑似目标 - 绿色段：识别为确定命中 image |
4. 按照要求上传识别目标的照片，请尽可能提供不同展示面的照片，提升识别准确度，每个面 4-5张照片即可。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7674182471/p932956.png)
5. 配置完成后，你就可以使用强化的专属模型了：

   | **使用范围** | **说明** |
   | --- | --- |
   | 图片解读技能 | 在图片理解设置页面，单击**刷新列表**，选择配置完成的专属模型。  image |
   | 工作流 | 1. 进入 AI 助理工作流配置页面，详情参考[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)。 2. 选择 **AI 能力** - **图片解读**执行动作，可以选用配置完成的专属模型。  image |

## **注意事项**

1. 模型学习是需要一定时间的，请关注模型是否已经完成最新上传图片的学习后再测试。
2. 如果分类特别多的时候，精确度会有大幅度衰减。经过测试，单个模型的图片分类类别在50以内准确度较高。

   > **[!NOTE]**
   >
   > 一个图片往往有多种不同的类别，可以试着通过多个模型分别进行不同维度的分类识别，然后通过工作流的形式串联起来，例如识别某个店铺是否符合巡检要求，可以按照要求加强生成多个模型，例如 清洁是否达标、摆设是否达标、安全是否达标等。
