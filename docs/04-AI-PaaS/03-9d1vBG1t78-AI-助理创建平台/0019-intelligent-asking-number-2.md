# 数据管理

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **背景信息**

### **概述**

**智能问数是**对话式数据 AI，通过自然语言理解、知识图谱为用户提供数据分析、数据洞察、数据可视化等功能；旨在帮助用户方便快捷地查找数据、简单直观地解读数据、智能深入地挖掘数据，**实现人人都有自己的专属数据分析师，提高数据查询及分析的效率和质量。**

### 用数痛点

| **痛点** | **说明** |
| --- | --- |
| 报表开发效率低 | 一份高质量的报表需要业务人员、技术人员等多个角色参与，建设周期长、开发效率低，往往需要几天甚至几周。 |
| 数据可视化展示复杂 | 传统的数据可视化需要技术人员介入，并且要具备一定的数据分析和图表制作的能力，实现门槛较高。 |
| 数据理解门槛高 | 没有数据基础的普通人面对复杂的报表时，无法快速得出有效的洞察结果，难以直观地理解和分析数据。 |
| 个性化数据分析难 | 传统 BI 报表只能展示固定的分析维度和指标，无法匹配业务的发展变化，一旦KP想要进行个性化分析时无法快速拿到分析数据。 |

### **核心能力**

通过聊天的方式，实现对钉钉官方应用数据、表格数据和数据库数据的分析和洞察。

## **操作步骤**

1. 使用智能问数相关能力，你需要了解如何在[创建组织内使用的 AI 助理](0005-create-a-dingtalk-ai-assistant-1.md)时进入 AI 助理创建页面。
2. 在 AI 助理创建页面，单击**技能** > **技能列表** > **添加**，并选择**为你推荐** > **智能问数**技能。

   ![使用智能问数](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4501954371/p889432.png)
3. 在智能问数配置页面，单击数据管理 > 添加，完成添加数据源，智能问数提供了三种数据来源，为钉钉应用数据、本地表格、多维表和本地数据库。介绍如下：

   - #### **钉钉应用数据：**

     开箱即用，打开后可以直接对钉钉的应用数据进行分析，包括考勤、审批、人事、差旅、合同、招聘、会议等。

     > 其他钉钉应用数据持续丰富中。

     | **钉钉应用数据** | **具体说明** |
     | --- | --- |
     | 钉钉考勤 | 支持分析员工出勤、请假、打卡、迟到等数据，比如看下我最近一周的打卡情况、帮我查看公司最近30天出勤率的变化趋势。 |
     | OA审批 | 支持分析审批单的处理耗时、审批状态等数据，比如看下本周我仍在处理中的审批单、查看这个月公司审批耗时最长的审批单。 |
     | 智能人事 | 支持分析在职员工的人数、年龄等基本信息，比如看下每个部门有多少在职员工、查看在职员工办公地点分布。 |
     | 智能差旅 | 支持分析出差天数、目的地分布等数据，比如帮我看下公司去年出差天数月趋势、看看本月员工的出差频率排行榜。 |
     | 智能合同 | 支持分析合同金额、状态等数据，比如看下公司近30天合同数变化趋势、最近半年花钱最多的合同是哪一个。 |
     | 智能招聘 | 支持分析招聘进展、渠道等数据，比如近三个月简历数量变化趋势、看下各个HR近一年的招聘量。 |
     | 钉钉会议 | 支持分析会议时长、开会次数等数据，比如帮我看下最近一个月我发起的会议数、公司最近7天每天平均会议时长。 |

     ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9336829171/p814030.png)
   - #### **本地表格：**

     1. 单击**添加数据管理**，选择**本地表格**。

        ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4501954371/p889436.png)
     2. 进入上传本地表格页面，你可以上传表格文件，目前支持的格式有 `.xls`、`.xlsx`、`.csv`，文件大小不能超过 10 M。

        > **[!NOTE]**
        >
        > - 初次使用时，可以点击“下载模板”，使用数据模板，按照固定格式上传数据，可以让AI学习的更好；或是单击“使用模板示例数据”，快速体验过程。
        > - 本地表格暂仅支持 1 个 sheet，最多仅支持 40 列。
        > - 本地表格的表头不能存在空值，字符长度最多不超过 30，表头不能重名，否则会影响大模型理解的准确度。
        > - 本地表格的内容不要包括合并单元格、图片等，否则会影响内容解析。

        ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9336829171/p814036.png)
     3. 上传完成后，单击下一步，进入配置表格内容：

        | **功能** | | **具体说明** |
        | --- | --- | --- |
        | 数据集名称 | | 用于做数据集的区分。 |
        | 数据集描述 | | 描述清楚数据集的分析场景和内容，当选择多个表时，用于帮助大模型进行表路由。 |
        | 表结构 | 字段原名称 | 系统自动解析本地表格的表头生成，不可修改。 |
        | 字段自定义名称 | 直观的中文名称，用于可视化展示的名称，简洁明确。例如，birth\_date 的中文名为“出生日期”。 |
        | 字段类型 | 系统自动解析生成，支持修改，包括字符串、数值型、时间型 |
        | 字段描述 | 详细描述字段用途和规则，帮助大模型更好的理解字段含义。例如 birth\_date 的备注可能是“格式为YYYY-MM-DD，用于计算年龄”。 |
        | 维度 | 维度是指分析数据的视角，比如日期、商品品类、产品名称等，用于帮助AI根据用户提问进行优先匹配 |

        配置完成后，单击右下角**确认**。

     3. 在配置数据集页面，单击新建数据集，配置内容如下：

## 使用智能**问数**

### **即问即答，人人都可进行数据分析**

- **像和真人一样对话，**支持用户通过自然语言进行交互和多轮对话，即使用户没有数据分析背景，也可以拿到想要的数据分析结果。
- **句句有回应，**支持多意图识别，能够处理用户在对话中的复杂需求和多种意图，即使是混杂的表达也可以理解并准确回应，帮助用户快速上手。
- **数据获取过程透明可验证，**把AI的思考过程白盒化，可以让AI的每一步都可以被看到，每一个结果都可以被追溯和验证。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4501954371/p889453.png)

### **智能洞察，一句话生成数据分析报告**

- **快速生成报表摘要**，并自动检测异常，降低报表的理解成本，AI直接帮助用户发现异常点、并标注出需要关注的地方。
- **AI帮你注入分析灵感**，支持没有数据分析背景的用户快速上手，一句话生成数据分析报告，让每个人都可以得出有价值的数据洞察，实现数据普惠。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9336829171/p814070.png)

## **常见问题**

- ### **同时选择“智能问数”技能和其他技能后，无法稳定回答正确结果**

  答：“智能问数”技能本身支持多轮对话和多意图识别，与部分其他技能冲突，建议仅保留“智能问数”技能，删除其他技能。
- ### **上传本地表格后，提示解析失败**

  答：请先按照模板格式上传，如果上传后仍解析失败，检查表格内容是否有合并单元格、数学公式、特殊字符，或者表头有纯数字，请避免这些情况的发生。
- ### **按照文档配置之后，外部系统为何无法正常访问数据库？**

  答：云数据库产商或者本地机房部署的数据库面向外部系统访问时，都有相关ip白名单设置，以阿里云RDS MYSQL为例：

  1. 确认预期云数据库 RDS，单击实例列表 > 白名单与安全组，进入白名单设置页面。

     ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1474939171/p815177.png)
  2. 单击添加白名单分组，在白名单分组页面，填写对应白名单。

     ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1474939171/p815179.png)
