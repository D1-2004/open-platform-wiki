# 执行逻辑

本文档将详细描述执行逻辑中的**循环**和**条件分支**两种执行动的使用方法。

## **适用人群**

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

## **准备工作**

正式使用前，需要提前了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

## **循环**

循环用于 AI 助理在流程执行中根据循环方式，循环执行流程。

### **操作步骤**

1. 在 AI 助理工作流搭建页面，单击**选择执行动作** > **逻辑/工具** > **循环**，进入循环配置页面。
2. 配置循环执行动作：

   | **配置项** | |  |  | **说明** |
   | --- | --- | --- | --- | --- |
   | 循环方式 | 按数组循环  按照数组列表逐条循环。 | 循环内容 | | 填写数组参数，可动态选择上游节点的输出数据。 |
   | 最大循环条数 | | 填写最大循环数据条数。  默认处理 100 条，最多不超过 500。 |
   | 按字符串循环  用分隔符对字符串分割后，逐条循环 | 循环内容 | | 填写字符串参数，可动态选择上游节点的输出数据。 |
   | 分隔符 | 常用分隔符 | - 英文逗号（,） - 英文分号（;） - 英文句号（.） - 英文空格 |
   | 自定义 | 自定义循环分隔符。 |
   | 最大循环数据条数 | | 填写最大循环数据条数。  默认处理 100 条，最多不超过 500。 |
   | 按数字循环  设置起始值、结束值、递增值，从起始值循环到结束值 | 循环位置 | | - 开始位置：循环开始位置 - 结束位置：循环结束位置 |
   | 循环递增值 | | 填写循环递增值。 |
   | 最大循环数据条数 | | 填写最大循环数据条数。  默认处理 100 条，最多不超过 500。 |

   至此，我们的循环执行动作就已经配置完成了，你可以在循环中选择你期望的其他执行动作进行数据处理。

## **条件分支**

条件分支用于根据客户的业务规则定制工作流，在不同的实际情况下，执行分支任务。

### **操作步骤**

1. 在 AI 助理工作流搭建页面，单击**选择执行动作** > **逻辑/工具** > **条件分支**，进入条件分支配置页面。
2. 配置条件分支执行动作：

   | **配置项** | | | **说明** |
   | --- | --- | --- | --- |
   | 名称 | |  | 填写分支名称。 |
   | 分支条件 | 表单模式 | 条件变量 | 选择上游节点的条件变量。 |
   | 判断条件 | 选择合适的判断条件。  不同的条件变量，判断条件不同。 |
   | 比对内容 | 填写对比内容，支持选择上游节点的数据内容。 |
   | 公式模式 | 公式模式 | 使用合适的公式完成分支规则。  请确保公式的返回结果为True/False，否则条件校验为不通过。  详情参考[如何使用表达式（公式）模式](0058-how-to-use-the-expression-formula-pattern.md)。 |
   | 代码模式 | 编写自定义代码完成分支规则  请确保公式的返回结果为True/False，否则条件校验为不通过。  详情参考[如何使用代码模式](0059-how-to-use-code-patterns.md)。 |

   你可以单击添加分支，配置多个执行逻辑，完成业务需求，至此，条件分支执行动作就可以配置完成。

## **常见问题**

### **选择一直循环后，要如何设置某种情况下跳出或终止循环？**

答：可以搭配逻辑/工具 > 执行逻辑下的**条件分支**、**跳出本次循环**、**终止全部循环**一起使用。比如在条件分支中设置规则，当满足某一条件时，正常执行循环内的操作；否则，就跳出循环或终止循环。
