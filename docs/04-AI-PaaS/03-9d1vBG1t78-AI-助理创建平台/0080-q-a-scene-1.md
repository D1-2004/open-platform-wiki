# 问答场景

问答场景解决问答中复杂或特定的查询要求，通过配置问答场景匹配用户意图，并指定查询的知识，提升回答准确度。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **能力介绍**

当用户上传了大量知识且知识内容较为复杂多样时，知识问答中会出现比较复杂或特定的查询要求，此时可通过配置问答场景来解决，提升知识问答解决率。问答场景主要是业务视角下用户意图的识别，比如维修场景、产品使用场景等。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7778813371/p881298.png)

## **前提条件**

- 了解[配置知识问答](0074-configure-q-a.md)并进入知识管理页面。

## **操作步骤**

1. 进入知识管理页面，单击**问答场景** > **新建问答场景**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7778813371/p881325.png)
2. 在问答场景页面，配置场景内容：

   | **配置项** | **说明** |
   | --- | --- |
   | 场景名称 | 言简意赅的描述业务上的问答场景。例如：产品使用手册。 |
   | 描述 | 详细描述该场景的具体涉及的问答用途以及含义，例如：用于查询产品使用介绍或使用答疑的问题识别。 |
   | 场景匹配规则 | 用于判断用户问题是否匹配该场景，支持关键词匹配和意图理解，包括：  - **关键词匹配**：通过用户描述内容中是否涉及关键词进行场景匹配。 - **意图理解**：表示通过理解用户描述的意图进行场景匹配。 **[!NOTE]**  - 若维护的内容是意图描述建议选择“意图理解”。 - 若维护内容是关键词建议选择“关键词匹配”。 |
   | 选择知识 | 用于指定该场景下知识召回范围，包括：  - **按照知识文档选择**：选择知识维护列表页已经学习的知识内容。 - **按照知识分类选择**：通过知识列表页维护的知识分类进行选择。 |

## **效果验证**

配置完成后，可通过调试台进行测试验证，在知识召回中，单击**调优**，即可查看问答场景匹配详情。
