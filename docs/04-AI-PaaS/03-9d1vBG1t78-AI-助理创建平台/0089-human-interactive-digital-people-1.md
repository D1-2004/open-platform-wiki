# 真人互动数字人

如果你需要一个真人互动的数字人形象，你需要准备本文包含的 3 个材料内容。

## **材料清单**

你需要提供 3 个视频材料，分别为**授权视频**、**音频录制视频**和**形象拍摄视频**。

| 灯光教程 | - 光线方向与手机/相机拍摄方向相同。 - 保证人物轮廓及脸部光线均匀，无明显的阴影。 - 可增加顶光，照亮人物轮廓。   image | - 主光源能照亮人物一侧脸部轮廓，光照均匀，摆放位置在人物的斜上侧方 45 度左右辅光需要弱于主光源两档，稍微补亮阴影侧的脸，及身体的大部分。 - 逆光需要照亮人物单侧大部分轮廓，及头顶的轮廓。 - 也可以采用暖光营造温馨的氛围，男士无特殊需求通常采用冷光。   image | - 人正面：灯光照亮人的下半身和脚部，不要有阴影（全身姿态下）。 - 人左右斜上方 45 度位置：灯光照亮面部，没有明显阴影，脸部光线均匀，无明显高光。 - 两侧灯光要照亮人形体轮廓，在人正侧及斜后侧位置架设。 - 人身后：背景光，目的是为了照亮绿幕，镜头中所有区域光线需要均匀，且无明显的阴影对比。   image | 无具体要求。 |
| 拍摄步骤 | 1. 检查镜头里人物的妆造,服饰,状态,设备的参数设置，灯光等是否都达到了优质的画面效果（参考前文内容）。 2. 正式录制前可以和被拍摄者进行交流，让其适应环境和熟悉拍摄流程，尝试来一小段发现问题，沟通好再进行录制。 3. 确保环境无杂音，模特先保持静默 15 秒左右，闭口不要露牙齿，眼睛正视镜头。 4. 模特正常口播 3 分钟 ～ 6 分钟，张嘴即发声，避免出现嘴巴张开却没有声音。可以伴随着自然的手势动作，但动作不要超过锁骨以上，尽量在胸部上下范围活动；具体出镜姿势、口播内容，可以根据最终的使用场景来确定，如后期用来制作财经知识视频，即可选择正装出镜，口播财经内容，这样整体情景比较一致。整个录制过程中保持环境安静，无背景音及他人说话，相机拍摄要外接指向型收音设备，说话时需吐字清晰，不能只重复口播内容或纯念数字 1234; | | | 1. 准备 5 秒 ～ 15 秒的文案内容，避免发音过于单一。 2. 确保周围环境安静无噪音。 3. 确保面部清晰无遮挡，无明显光影变化。 4. 前 30 秒闭嘴，后 5 秒 ～ 15 秒开口大声阅读文案。 |
