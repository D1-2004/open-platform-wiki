# 待办

如果你需要使用待办的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **操作步骤**

1. 单击**选择执行动作**，选择 **待办 > 创建钉钉待办**。
2. 配置创建钉钉待办：

   | **配置项** | **说明** |
   | --- | --- |
   | 任务标题 | 待办的标题。 |
   | 执行人 | 待办的执行人。  **[!NOTE]**  - 支持单击 **“⊕”**，设置变量信息，需选择钉钉用户 UserID - 支持单击 “人员标识”，使用选人组件，选择组织内人员。 |
   | 截止时间 | 待办任务的截止日期。 |
   | 任务描述 | 对待办任务的文字描述。 |
   | 参与人 | 待办的参与人员。  **[!NOTE]**  - 支持单击 **“⊕”**，设置变量信息，需选择钉钉用户 UserID - 支持单击 “人员标识”，使用选人组件，选择组织内人员。 |

## **示例**

为自己创建周报待办任务为例，配置待办执行动作：

| **配置项** | **说明** |
| --- | --- |
| 任务标题 | 填写：周报。 |
| 执行人 | 你可以单击**“⊕”** > **步骤变量** > **对话人**，选择 staff id。  选择对话人的 staff id，目的是让每一个与之对话的用户，都可以创建属于自己的周报任务。 |
| 截止时间 | 你可以单击“日历标识”，使用时间组件，选择你需要的截止时间，本示例选择2024-06-21 17:00:00。 |
| 完成周报 | 填写：注意完成周报任务，不要忘记哦。 |
| 参与人 | 你可以单击**“⊕”** > **步骤变量** > **对话人**，选择 staff id。  选择对话人的 staff id，目的是让每一个与之对话的用户，都可以创建属于自己的周报任务。 |

此时，创建钉钉待办的执行动作已经完成，看到这里，你可以搭建属于你的专属待办管家了。
