# 创建任务

如果你需要使用创建任务的执行动作，请了解如何在[创建 AI 助理工作流](0037-create-an-ai-assistant-workflow-1.md)时添加执行动作。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理**

## **操作步骤**

1. 单击**选择执行动作**，选择 **Teambition** > **创建任务**。
2. 配置创建任务执行动作：

   | **配置项** | **说明** |
   | --- | --- |
   | 任务所属项目 | 任务归属项目。 |
   | 任务标题 | 任务的标题。 |
   | 执行者 | 任务的执行者。  仅支持引用组织内人员。任务执行人仅支持设为一个人，若为多人字段则默认为第一个人 |
   | 截止时间 | 选择任务的截止时间。 |
   | 备注 | 任务的备注。  支持插入变量，也支持输入文本、图像和链接 |
   | 参与者 | TB 任务的参与人。  **[!NOTE]**  - 支持单击 **“⊕”**，设置变量信息，需选择钉钉用户 UserID。 - 支持单击 “人员标识”，使用选人组件，选择组织内人员。 |
