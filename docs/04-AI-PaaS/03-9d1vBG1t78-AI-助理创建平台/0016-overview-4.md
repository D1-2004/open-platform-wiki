# 概述

如果你需要了解 AI 助理的能力的相关信息，你可以参考本文档内容。

**适用人群**：**所有人** ；**适用范围**：**组织内创建的 AI 助理/助理市场创建的 AI 助理**

AI 助理拥有丰富的能力，能力包括官方能力、三方能力、自定义的能力和拟人操作能力。

## **官方能力**

| **能力** | **说明** |
| --- | --- |
| 智能对话 | 能够回答用户日常生活中遇到的各类问题，并可联网查询最新信息，如天气、新闻等。 |
| 请假助手 | 帮你生成请假内容并直接提交请假审批 |
| 智能创作 | 帮你创作内容或润色文案 |
| 智能待办 | 能够帮你创建、查询或修改待办 |
| 智能问数 | 通过聊天的方式，实现对钉钉官方应用数据、表格数据和数据库数据的分析和洞察 |
| 预约日程 | 帮你智能创建日程，每一天都井井有条 |
| 钉钉助手 | 输入你想用的钉钉功能，一键即达 |
| 业务数据填报（宜搭） | 开启后，可对话使用应用，如数据填报、数据分析等 |

## **三方能力**

| **能力** | **说明** |
| --- | --- |
| 1688商品搜索 | 在 1688 平台搜索商品信息 |
| 查询微博热门 | 实时查询热门微博资讯 |
| 查询知乎热榜 | 查询知乎热点问答 |
| 查询抖音热门视频 | 查询抖音热门视频 |
| 查询头条热点 | 查询头条热点新闻 |
| 论文检索 | 通过英文关键词从 arXiv 平台检索英文论文 |
| 汇率查询 | 根据用户输入查询相应汇率 |
| 病症查询 | 通过关键字查询疾病信息及相关症状 |
| 药品查询 | 通过关键词搜索药品相关信息 |

## 自定义能力

如果官方能力和三方能力都无法满足你的需求，可以将现有业务接口用于开发 AI 的自定义能力，详情参考[自定义能力](0024-overview-6.md)。

## **拟人操作能力**

AI 助理面向钉钉的用户和开发者提供一种模拟真人操作钉钉应用和网页的交互体验，有利旧企业老旧系统良好兼容钉钉 AI 助理。例如你可以做一个 AI 助理，实现通过自然语言指令，让AI助理帮用户处理OA、宜搭等常用且繁琐复杂的钉钉应用操作。

你可以通过2种模式创建 AI 助理的拟人操作：

- 学习模式：即“你做它学”，你可以按照你希望用户操作应用或网页的方式“录制”完整的操作流程；录制完成的拟人操作可被AI助理调用，用户未来即可通过一句话自然语言指令触发拟人操作的操作执行。

  > 学习模式目前正在灰度中，后续即将全量，敬请期待。
- 代码模式：通过JavaScript源码开发RPA脚本，并通过配置方式保存为AI助理可使用的插件，实现操作网页或自有应用系统。

### **代码模式**

开发者可以通过编写脚本（JavaScript）来操作钉钉内的企业应用，实现现有系统的无侵入式快速 AI 集成。你只需依照拟人操作（RPA）描述协议来开发脚本，制定相应的插件描述清单，并将该协议的 JSON 内容复制粘贴到高级自定义能力开发页面中，就可以完成自定义能力的开发，详情参考[代码模式开发指南](https://open.dingtalk.com/document/aipass/development-guide-1)。
