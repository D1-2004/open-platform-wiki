# 概述

通过本文档了解炼丹炉大模型平台的相关介绍信息。

## **介绍**

炼丹炉大模型服务平台是一站式的企业专属大模型生产平台，基于通义千问和各个三方大模型，提供企业专属大模型开发和应用的整套工具链。

- **面向对象：**企业、开发者及服务商。
- **核心能力：**支持开箱即用的应用调用，大模型训练微调和一站式在线灵活部署。
- **服务形式：**支持一键与钉钉AI助理打通、通过API服务的方式输出给客户，方便客户进行集成和使用专属大模型能力。

## **名词解释**

### **模型服务**

- **模型广场**

  在这里您可以根据业务所需挑选通义系列大模型、第三方大模型等接入到企业解决方案中
- **体验中心**

  通过选择模型，可选择1-3个模型快速体验或对比模型效果
- **我的模型**

  在这里您可以管理公共模型的可使用范围、专属模型的训练周期管理

### **模型训练**

- **知识问答**

  根据企业自有知识库，在基础大模型之上训练企业专属问答模型
- **数据查询**

  根据企业自有数据，训练和调优用数场景的模型服务
- **自动填表**

  根据企业表单数据，训练智能提交表单的模型服务

### **数据中心**

平台统一的数据管理模块，支持多格式的结构化及非结构化数据管理，应用于模型训练

### **系统管理**

您可以在这里查看专属模型的用量统计，以获得模型的使用情况
