# 数据管理

本文档介绍在炼丹炉大模型平台创建数据的步骤。

## 背景介绍

上传企业自有知识库数据，作为大模型训练的语料。

| **数据集类型** | **是否包含排序** | **说明** | **使用场景** |
| --- | --- | --- | --- |
| 文本对话 | 无排序 | 单轮或多轮的文本对话数据，单个提问和回答一一对应 | 模型训练-知识问答（SFT） |
| 包含排序 | 单轮或多轮的文本对话数据，单个提问对应多个回答，需要对多个回答进行效果排序 | 模型训练-知识问答（RLHF） |
| 泛文本 | —— | 特定行业方向/场景下的大规模语料 | 模型训练-知识问答（Pretrain） |

## **新建文本对话数据集**

### **无排序数据集（一问一答）**

单轮或多轮的文本对话数据，单个提问和回答一一对应，用于**通用模型训练**。

1. 进入炼丹炉大模型平台，点击**数据管理**，点击**新建数据集**。
2. 填写数据集名称，选择数据集类型为**文本对话**，选择**无排序**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4386129171/p813647.png)
3. 可下载模板，查看数据集文档格式，符合格式要求的文档，可以直接上传。

   > **[!NOTE]**
   >
   > 文本对话无排序数据集，要求数据量范围（200~10000）条。

   **格式示例：**

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8392326071/p761941.png)
4. 点击左下角**创建数据集**按钮，完成创建。

### **包含排序数据集（一问多答）**

单轮或多轮的文本对话数据，单个提问对应多个回答，需要对多个回答进行效果排序，用于能力模型训练-知识创作（RLHF）。

1. 进入炼丹炉大模型平台，点击**数据管理**，点击**新建数据集**。
2. 填写数据集名称，选择数据集类型为**文本对话**，选择**包含排序**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4386129171/p813649.png)
3. 可下载模板，查看数据集文档格式，符合格式要求的文档，可以直接上传。

   > **[!NOTE]**
   >
   > 文本对话含排序数据集，要求数据量范围（100~2000）条。

   **格式示例：**

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2530565071/p759633.png)
4. 点击左下角**创建数据集**按钮，完成创建。

## **新建泛文本数据集**

特定行业方向/场景下的大规模语料，支持10M以下的**docx、tex、pdf**格式文件。

1. 进入炼丹炉大模型平台，点击**数据管理**，点击**新建数据集**。
2. 填写数据集名称，选择数据集类型为**泛文本**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4386129171/p813650.png)
3. 点击**添加知识**，选择本地文件和钉钉文档进行上传。
4. 点击左下角**创建数据集**按钮，完成创建。
