# 敏感词管控

## **概述**

敏感词管控功能是一种内容安全保障机制，可识别**用户输入或者大模型输出**的敏感词，主要用于识别、过滤、拦截和管理可能存在风险的文本内容。该功能允许企业根据自身业务需求定制敏感词库和过滤规则，主要有以下 2 个作用：

- **敏感信息输入拦截：**当员工传输到大模型的信息存在敏感信息时，可进行拦截，避免敏感信息传输至大模型，避免公司数据/知识外泄；
- **敏感信息输出拦截：**自动检测大模型生成的文本中的敏感词汇，包括公司敏感信息、政治敏感、色情、暴力、歧视等敏感内容，并进行拦截；确保平台生成的内容符合法律法规和企业政策要求，避免因不当内容造成的负面影响；

### **编辑敏感词规则**

在编辑界面中，对当前敏感词进行编辑，如下图所示：

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7396943871/p1085675.png)

配置项介绍和说明：

| **配置项** | **说明** |
| --- | --- |
| 词库名称 | 填写词库名称。 |
| 敏感词 | - **关键词匹配**：支持按照关键词进行匹配，最多支持**1500**个关键词，每次关键词限制**32**个字符，以回车键隔开。 - **正则表达式**：正则表达式是一种用于文本匹配的模式，可以用来在字符串中查找特定内容，上限**100**个，并自动校验正则表达式语法的正确性。例如：    - 匹配文案是否有手机号码：^1[3-9]\d{9}$   - 匹配所有含有敏感词“退款”的句子：.*?退款.*? |
| 生效范围 | - **全部智能体**：敏感词对全部智能体生效。 - **部分智能体**：仅对选中的智能体生效。 |
| 生效方式 | - **拦截，同时后台审计记录**：对包含敏感词的内容进行拦截，同时在后台进行记录。 - **不拦截，仅后台审计记录**：对包含敏感词的内容不拦截，仅在后台进行记录。 |
| 审计范围 | - **用户发送的对话内容：**支持设置回复固定文案，提供默认文案：抱歉，由于会话内容包含敏感词，暂无法回答您的问题。 - **智能体输出的内容**    - 支持设置回复固定文案，提供默认文案：抱歉，由于会话内容包含敏感词，暂无法回答您的问题。   - 仅对敏感内容打\*脱敏处理。输出过程中当敏感内容输出的同时，做\*的脱敏处理。  image |

## **命中记录审计**
