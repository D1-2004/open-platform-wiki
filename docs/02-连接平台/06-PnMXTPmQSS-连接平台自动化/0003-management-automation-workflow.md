# 管理自动化流程

## **全局管理**

顶部TAB切换至**流程管理**，查看全部流程、运行中的流程、未启用的流程。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8300275871/p754775.png)

## **单个流程管理**

> **[!NOTE]**
>
> 除了管理员外，**普通成员只能管理（查看/编辑/删除）自己创建的流程**，而不能管理他人创建的流程。

| **操作** | **方法** |
| --- | --- |
| 启用/禁用流程 | 在流程列表中，通过开关按钮控制：打开=运行，关闭=禁用。  image.png |
| 编辑/删除流程 | 点击更多，对流程进行**编辑**或**删除，**或直接单击流程的空白区域，**进入流程编辑页面**。  image.png |

## **查看执行记录与排查**

在流程编辑页面，点击左上角**执行记录**，可以查看：

- 累计执行次数
- 执行成功次数
- 执行失败次数

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8300275871/p754778.png)

单击某次执行记录的**详情**，可以一键复制错误信息，便于原因排查。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2953786071/p754779.png)
