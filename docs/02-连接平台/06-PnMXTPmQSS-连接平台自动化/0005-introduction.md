# 介绍

## **简介**

群聊自动化，通过**自动化小助手**（钉钉连接平台提供），**智能联通不同应用**，**将日常重复的工作自动化。**不同的群成员可以创建多条不同的自动化流程，**降低人力成本，提高工作效率**。

## **群内添加自动化小助手**

> **[!NOTE]**
>
> 每个群组内**最多只能添加1个**自动化小助手。

1. 选择一个**内部群**或**外部群**，单击群聊会话右上角**群设置** > **机器人**

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0097069471/p966318.png)
2. 单击**添加机器人。**![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2859964071/p755066.png)
3. 单击**自动化小助手。**

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0097069471/p753527.png)
4. 单击**添加** > **完成并开始配置，**即可添加自动化小助手入群，并开始配置自动化流程。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6679175871/p1091644.png)
5. 后续步骤，可根据[创建自动化流程](0002-automated-process-usage-guide.md)完成配置。
