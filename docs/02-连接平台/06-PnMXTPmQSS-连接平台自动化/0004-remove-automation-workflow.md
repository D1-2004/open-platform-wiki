# 移除自动化流程

## **权限说明**

在**群聊自动化**中，只有以下角色才有移除权限：

- 群主
- 群管理群
- 自动化小助手的创建者

## **操作步骤**

1. 单击右上角**更多**图标，然后再单击**移除机器人**。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9300275871/p754785.png)
2. 单击**移除**，即可移除自动化小助手。

   > **[!IMPORTANT]**
   >
   > 移除后，所有群成员创建的自动化流程都将失效。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9300275871/p754786.png)
