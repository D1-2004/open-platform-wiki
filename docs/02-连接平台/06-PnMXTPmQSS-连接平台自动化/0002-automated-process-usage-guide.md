# 创建自动化流程

## 权限说明

**群聊自动化**，在自动化小助手内，不同群成员的创建权限如下：

| **角色** | **创建权限普通群成员** |
| --- | --- |
| 群主和群管理员 | ✅ 可以创建自动化流程， |
| 普通群成员 | ✅ 在群设置 > 群管理 > **仅群主和群管理员可管理**开关**关闭**时，才可以创建自动化流程image.png |

## **创建方式**

| **创建方式** | **适用人群** | **特点** |
| --- | --- | --- |
| 从模板创建 | 新手用户 | 模板提供预置的触发条件和执行动作，可在此基础上修改。 |
| 从空白创建 | 有经验的用户 | 完全自定义触发条件和执行动作。 |

## **创建流程**

### **从模板创建流程**

1. 顶部 TAB 切换至**流程新建**，选择一款模板，单击**立即使用**。

   > **[!NOTE]**
   >
   > 本流程以**新人入群时，机器人发送仅新人可见的通知**为例，其他模块类似。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754742.png)
2. 模板提供了预置的触发条件和执行动作，可在此基础上，根据自己的需求配置**触发条件**和**执行动作**的具体内容。

   1. 配置触发条件：

      ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754745.png)
   2. 配置执行动作：

      ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754747.png)
3. 可点击左上角**修改流程名称（图示中①）**，确认后单击右上角**保存（图示中②）**按钮，最后点击**发布**即可。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754751.png)

### **从空白创建流程**

1. 在流程新建页单击**从空白创建**。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754754.png)
2. 选择**触发条件**为**定时触发**，并配置触发时间。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754757.png)
3. 选择**执行动作**，并配置其具体内容。

   > **[!NOTE]**
   >
   > 本示例以**消息通知**为案例，若需使用其他执行动作，可自行选择并配置。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754760.png)
4. 按照需求配置执行动作内容。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754761.png)
5. 根据需要可在某一节点**增加新的执行动作**；或者根据需要，**删除执行动作**。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754766.png)
6. 可点击左上角**修改流程名称（图示中①）**，确认后单击右上角**保存（图示中②）**按钮，最后点击**发布**即可。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7069175871/p754771.png)
