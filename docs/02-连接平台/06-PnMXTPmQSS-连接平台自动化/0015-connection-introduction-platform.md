# 介绍

## **简介**

知识库自动化，通过配置自定义规则，设置**“触发条件”**与**“执行动作”**后，知识库可以在不需要人工干预的情况下实现自动归档、AI收集信息、群内播报、ISO文档管控等一系列任务，实现知识库内容自动管控等。

### **功能亮点**

- **高效自动化**：通过自定义规则，设置触发条件与执行动作，知识库可自动执行任务，无需人工干预，节省人力成本，提高工作效率。
- **精准信息同步**：自动化流程确保知识库中的数据和信息及时、准确地同步到各个部门和人员，避免因信息滞后或错误导致的决策失误，提升企业运营效率和竞争力。
- **灵活的规则设置**：支持企业根据自身业务需求和管理要求，灵活定义规则，涵盖文档分类、审批流程、信息推送等多个方面，满足不同企业的多样化需求。
- **深度整合钉钉生态**：与钉钉的其他功能模块无缝对接，如与审批流程、日历安排等结合，实现知识管理与企业日常办公的深度融合，打造一体化的办公流程。

### **适用人群**

- **知识管理员**：集中管理团队的文档、资料等知识资产，通过自动化流程，自动对各类文档进行分类和归档，节省人工整理的时间。
- **行政人员**：自动分类归档文档，设置自动提醒的行政任务，确保工作有序。
- **市场营销人员**：快速生成营销文案，设计宣传海报，进行市场数据分析，提升推广效果。
- **市场专员：**通过知识库自动化 AI技术对市场数据进行分析和预测，为营销策略提供数据支持。
- **客服人员：**通过知识库自动化向 AI 问答，自动识别客户问题的意图，从知识库中自动提取相关答案，为客户提供准确的解答。
- **个人用户：**可以将钉钉知识库作为个人知识管理中心，设定规则将工作资料、兴趣爱好资料等自动归档等，
- **内容运营：**利用AI音频生成器根据文档内容自动添加旁白或配音，丰富内容呈现形式。

## **实现场景**

- 订阅知识库内文档创建/更新 。
- 每周定时提醒团队成员更新周报。
- 每日行业情报收集与推送。
- 用AI一句话生成一本书/课程。
- 用AI 订阅每日电台。

## **知识库自动化入口**

> **[!NOTE]**
>
> 知识库的所有者，或者有管理权限的协作者能够开启自动化流程。

1. 通过浏览器或客户端打开钉钉知识库，并确定需要配置自动化的知识库。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969175871/p1091670.png)
2. 进入知识库后，点击左下角**自动化**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969175871/p955688.png)
3. 后续步骤，可根据[创建自动化流程](0002-automated-process-usage-guide.md)完成配置。
