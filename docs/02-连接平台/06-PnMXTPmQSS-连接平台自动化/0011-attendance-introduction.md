# 介绍

## **简介**

考勤自动化旨在帮助用户**将考勤数据与不同应用打通**，实现工作流程的自动化。通过配置自动化流程，你可以：

- 🕒 **自动通知指定用户/群**：打卡异常、迟到早退等事件实时推送，让管理无死角。
- 🔧 **考勤结果动态监控**：数据变更即时触发后续动作，告别手动轮询。
- 👥 **智能化团队联动**：考勤状态变化自动关联待办、消息、AI表格等应用，提升协作效率。

## **考勤自动化入口**

> **[!NOTE]**
>
> 只有考勤管理员才能使用考勤自动化功能，仅支持在电脑端钉钉使用。

1. 工作台中，单击**考勤打卡**应用。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7679175871/p758046.png)
2. 单击**考勤自动化**，选择一个模板创建流程并**立即使用**，或**从空白新建**流程。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7679175871/p758047.png)
