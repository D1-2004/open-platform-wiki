# 什么是连接平台

本文档旨在全面介绍钉钉连接平台的核心概念、适用对象、使用路径及典型应用场景，帮助开发者和管理员正确理解并高效使用该平台。

## **什么是连接平台**

钉钉连接平台是一种基于低代码/零代码理念的集成工具，用于实现应用与应用之间的无缝连接。传统系统间集成通常依赖专业技术人员编写接口代码，而通过连接平台，即使是非技术人员也可以通过图形化界面快速搭建跨系统业务流程。

该平台帮助企业显著**降低**集成实施的**周期**和**成本**，同时保障流程执行的安全性与稳定性。

## **背景与目标**

在企业数字化转型过程中，不同应用系统之间的数据孤岛和业务割裂问题日益突出。为解决这一挑战，钉钉推出**连接平台**，旨在通过低代码甚至零代码的方式，实现跨应用、跨系统的自动化业务流程集成。

连接平台的设计初衷是降低技术门槛，让非专业开发人员（如业务运营、管理员等）也能快速构建高效、稳定的集成流程。通过可视化编排能力，用户可以将多个系统的触发事件与执行动作串联起来，打通钉钉内部应用与外部SaaS系统之间的壁垒，从而提升组织协作效率，缩短集成周期，减少开发成本。

## **产品优势**

- **灵活搭建**：提供可视化流程编排界面，支持拖拽式配置；内置多种流模板，可一键订阅启用，大幅降低使用门槛。
- **资源丰富**：集成大量钉钉官方连接器（如审批、机器人、通讯录）及第三方SaaS连接器（如金蝶、用友、抖音、北森），覆盖财务、人事、营销、办公等多个业务领域。
- **稳定高效**：具备高可用的执行链路，支持失败自动重试机制，并提供完整的运行日志与监控面板，便于排查异常。
- **接入简单**：支持多种协议（如 RESTful API、Webhook）和鉴权方式（如 OAuth2.0、API Key），兼容企业网关集成需求。

## 适用对象与使用路径

### **适用对象**

本平台主要面向以下三类角色：

- **开发者**：负责自建连接器开发、API对接、流程调试，需具备一定的编程基础。
- **企业管理者/管理员**：负责审批流程配置、权限管理、连接流上线与监控。
- **服务商（ISV）**：为多个企业提供标准化或定制化的集成解决方案，可通过连接平台快速交付。

### **支持的应用类型**

根据钉钉开放平台[应用类型介绍](https://open.dingtalk.com/document/development/introduction-to-application-types)，连接平台支持以下应用形态：

- 企业内部自建应用
- 第三方企业服务应用（ISV）
- 钉钉原生应用（一方应用）

## **基本概念**

### **连接器**

连接器是封装特定业务系统能力的组件，能够集中某一领域的功能接口，支持对外暴露触发事件和执行动作，从而参与流程编排。

每个连接器对应一个系统（如钉钉审批、金蝶云星空），其作用是作为桥梁连接外部系统与连接平台。

**核心能力**

- **触发事件**：指外部系统状态发生变化时，向连接平台推送通知以启动流程；可通过 Webhook 或轮询机制实现监听；
- **执行动作**：指连接平台调用外部系统的 API 接口来完成某项具体操作，例如发送消息、创建审批单、更新数据等。

  > 示例：当“多维表”新增一行数据时，触发事件被激活；随后执行动作为“调用机器人发送群消息”。

**连接器分类**

- **官方连接器**：由钉钉提供的用于连接其自身应用的连接器，如审批、机器人、通讯录、考勤等；
- **三方连接器**：由第三方 SaaS 厂商提供并接入的连接器，如金蝶、用友、抖音、北森等；
- **自建连接器**：企业自行开发并注册的连接器，用于对接内部系统（如ERP、CRM）；需通过开发者后台申请并通过认证方可使用。

### **连接流**

连接流是通过图形化界面将多个连接器的**触发事件**与**执行动作**依次组合而成的自动化流程。它允许用户跨系统编排业务逻辑，实现“当……就……”类型的规则自动化。

例如：“当OA审批通过后，自动在多维表中新增一条记录，并通知指定群组”。

连接流支持复杂逻辑编排，包括条件分支、循环处理、数据映射等功能，适用于大多数企业级集成场景。
