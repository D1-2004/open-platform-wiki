# 创建连接项目

如果你需要创建连接项目，你可以参考本文档操作步骤完成创建操作。

## **前提条件**

已经[成为连接平台管理员](0002-become-a-connected-platform-administrator-1.md)。

## **操作步骤**

1. 登录开发者后台，单击**开放能力 > 连接平台**。进入连接平台页面。
2. 单击**配置中心** > **连接项目** > **创建项目**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2506584871/p1090355.png)
3. 填写连接项目配置信息，最后单击**确定**。

   | **配置项** | **描述** |
   | --- | --- |
   | 项目名称 | 填写你的项目名称。 |
   | 项目描述 | 简要描述项目信息。 |

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2506584871/p1090358.png)

## **后续步骤**

项目创建完成后，你可以管理连接项目，详情参考：

- [管理连接项目](0004-manage-project-members.md)
