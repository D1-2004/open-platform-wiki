# 管理连接项目

如果你需要添加项目协同成员，你可以参考本文档操作步骤完成添加操作。

## **前提条件**

完成[创建连接项目](https://open.dingtalk.com/document/connector/create-a-connection-project)流程。

## **管理项目成员**

1. 登录开发者后台，单击**开放能力** > **连接平台**。
2. 单击**配置中心** > **连接项目 > 目标连接项目**，进入项目详情页。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4506584871/p1090365.png)
3. 单击**成员信息**，配置项目成员**。**

   | **成员** | **描述** |
   | --- | --- |
   | 项目管理员 | 具有项目成员的所有权限，还具有新增删除项目成员的权限。无创建项目和删除项目权限。 |
   | 项目成员 | 具有项目关联的连接器、连接流的操作权限。 |

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4506584871/p1090366.png)

## **管理连接流/连接器**

### **添加连接流到连接项目**

1. 创建连接项目后，单击**我的连接** > **我的连接流**。
2. 确认需要迁移的连接流，单击**更多** > **移至项目**，迁移至期望的连接项目。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4506584871/p737843.png)

### **添加连接器到连接项目**

1. 创建连接项目后，单击**我的连接** > **我的连接器**。
2. 确认需要迁移的连接器，单击**更多** > **移至项目**，迁移至期望的连接项目。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4506584871/p737846.png)

### **查看连接项目下的连接器/连接流**

在连接器/连接流右侧下拉框中选择创建的项目，即可查看该项目像的连接器/连接流。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4506584871/p737859.png)
