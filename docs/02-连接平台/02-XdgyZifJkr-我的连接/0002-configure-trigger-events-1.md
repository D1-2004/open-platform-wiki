# 配置触发事件

触发事件是连接流的入口节点。一旦该事件被触发，连接流将开始运行。如果你需要配置触发事件，可以按照本文档中的操作步骤完成配置。

## **前提条件**

完成[创建连接流](0001-create-a-connection-flow-1.md)的流程。

## **操作步骤**

1. 单击触发事件节点（即流程首节点），在配置界面右侧会弹出触发事件配置页。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5251774871/p759973.png)
2. 在连接器选择页面，浏览并找到你需要的连接器，并单击选中它。选定连接器后，系统会在“触发事件”页面，自动显示该连接器提供的所有可用触发事件。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5251774871/p759981.png)
3. 选择需要的触发事件，配置结束后图例如下：

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5251774871/p759988.png)
