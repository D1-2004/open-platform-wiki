# 创建连接流

如果你需要创建连接流，可以参考本文档操作步骤完成创建。

## **前提条件**

完成[成为钉钉开发者](../../01-应用开发/01-XOnnmGCTbn-开发指南/0006-get-developer-permissions.md)的流程。

## **操作步骤**

1. 登录[开发者后台](https://open-dev.dingtalk.com/)。
2. 单击**开放能力** > **连接平台** > **我的连接** > **我的连接流** > **创建连接流**，进入流程编排界面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0306584871/p1089388.png)
3. 如果你需要编辑连接流的名称，你可以单击左上角编辑标识。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7670774871/p759966.png)

## **后续步骤**

连接流创建完成后，你需要[配置触发事件](0002-configure-trigger-events-1.md)。
