# 发布连接流

连接流配置完成后，可以发布创建好的连接流。本文将为您介绍如何发布连接流。

## **前提条件**

完成[保存并调试连接流](0005-save-and-debug-the-connection-flow.md)的流程。

## **操作步骤**

1. 单击**发布**，完成连接流的发布操作。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3134774871/p762299.png)
2. 发布成功后，流程版本将变更为已发布。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3134774871/p762301.png)

## **后续步骤**

发布完成后，你可以[使用连接流](0007-using-connection-flow-1.md)。
