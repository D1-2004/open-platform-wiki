# 概述

## **简介**

管理员可以通过公告发布公司或单位的规章制度、节假日信息等通知，快速通知到全体员工。更多功能详情可参考[钉钉使用手册-公告](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/mM3zoYAw1Rr8Dan5xEk6WnZ07y9NpXxD)。

## **执行动作**

| **连接器名称** | **执行动作** | **描述** |
| --- | --- | --- |
| [公告](https://open-dev.dingtalk.com/fe/connector#/market/connector/G-CONN-101886C44A9A213DF5B1000Q?corpId=ding32fff839a3e0105d) | 创建企业公告 | 管理员可以通过该接口创建钉钉企业公告。 |
| 更新公告 | 根据公告ID修改企业公告。 |
| 删除公告 | 根据公告ID删除企业公告 |
| 获取公告详情 | 根据公告ID获取企业未删除公告详情 |
| 获取公告ID列表 | 获取企业未删除的钉钉公告id列表 |
| 获取公告分类列表 | 获取企业公告未删除分类列表 |
| 获取用户可查看的公告 | 列出用户当前有权限看到的10条公告。 |
| 获取公告钉盘空间信息 | 获取公告钉盘空间信息。 |
