# 概述

## **简介**

内部信息统一管理，清晰展示组织架构，快速找人，同时保障企业通讯数据安全。通讯录设置、管理、可见性管理等更多功能介绍请参考[钉钉使用手册-通讯录](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/Y7kmbpxy30LLzLq2?dontjump=true#)。

## **触发事件**

| **触发事件** | **描述** |
| --- | --- |
| 企业删除 | 当企业被删除时，会触发企业删除事件。 |
| 企业信息变更 | 当企业信息变更时，会触发企业信息变更事件。 |
| 创建角色 | 当用户操作创建新的角色时，会触发创建角色事件。 |
| 修改角色 | 当用户操作修改角色信息时，会触发修改角色事件。 |
| 删除角色 | 当用户操作删除角色时，会触发删除角色事件。 |
| 创建部门 | 当用户操作创建新的部门时，会触发创建部门事件。 |
| 修改部门 | 当用户操作修改部门信息时，会触发修改部门事件。 |
| 删除部门 | 当用户操作删除部门时，会触发删除部门事件。 |
| 企业员工激活 | 当企业员工信息被激活时，会触发企业员工激活事件。 |
| 企业员工角色变更 | 当企业员工角色被修改时，会触发企业员工角色变更事件。 |
| 企业员工部门变更 | 当企业员工部门被修改时，会触发企业员工部门变更事件。 |
| 企业内部用户变更 | 当企业内部用户变更时，会触发企业内部用户变更事件。 |
| 通讯录用户增加 | 当通讯录有新的用户增加时，会触发通讯录用户增加事件。 |
| 通讯录用户离职 | 当通讯录有用户离职时，会触发通讯录用户离职事件。 |

## **执行动作**

| **执行动作** | **描述** |
| --- | --- |
| 创建用户 | 企业用户添加。 |
| 更新用户 | 根据用户ID，更新用户信息。 |
| 删除用户 | 根据用户ID，删除用户。 |
| 查询用户详情 | 根据用户ID，查询用户详情。 |
| 获取管理员列表 | 查询管理员列表。 |
| 获取未登录钉钉的员工列表 | 根据查询日期，查询企业下未活跃用户或活跃用户列表数据。 |
| 根据userid获取用户unionid | 根据userid获取用户unionid。 |
| 根据unionid获取用户userid | 根据unionid获取用户userid。 |
| 创建角色 | 企业角色添加。 |
| 更新角色 | 根据角色ID，更新角色名称。 |
| 删除角色 | 根据角色ID，删除角色。  **[!NOTE]**  删除角色前确认该角色下面的所有员工都已经被删除该角色。 |
| 获取角色详情 | 根据角色ID，获取角色详情。 |
| 获取角色列表 | 根据分页参数，查询角色列表。 |
| 获取角色组列表 | 根据角色组ID，查询角色组信息。 |
| 批量增加员工角色 | 企业在做企业员工管理的时候，需要对部分员工进行角色分类，根据角色ID和用户ID，可以批量为员工增加角色信息。 |
| 批量删除员工角色 | 根据角色ID和用户ID，可以批量删除员工角色信息。 |
| 设定角色成员管理范围 | 更新角色成员管理范围，指定企业成员在角色下管理部门的范围。 |
| 获取指定角色的员工列表 | 根据角色ID，查询指定角色的员工列表。 |
| 更新部门 | 根据部门ID，更新部门信息。 |
| 删除部门 | 根据部门ID，删除部门。 |
| 获取部门详情 | 根据部门ID，查询部门详情。 |
| 获取部门员工人数 | 根据部门ID，获取部门员工人数。 |
| 获取子部门ID列表 | 根据部门ID，获取该部门的子部门ID列表。 |
| 获取部门下人员列表 | 根据部门ID，获取部门下人员列表。 |
| 获取部门用户userid列表 | 根据部门ID，查询部门userid列表。 |
| 获取指定用户的所有父部门列表 | 根据用户ID，查询指定用户的所有父部门列表。 |
| 获取指定部门的所有父部门列表 | 根据部门ID，查询指定部门的所有父部门列表。 |
| 获取管理员通讯录权限范围 | 获取通讯录权限范围。 |
| 添加外部联系人 | 添加企业外部联系人 |
| 更新外部联系人 | 根据用户ID，更新外部联系人信息。 |
| 获取外部联系人列表 | 根据分页参数，获取外部联系人列表。 |
| 获取外部联系人详情 | 根据用户ID，获取外部联系人详情。 |
| 获取企业信息（行业通讯录） | 获取行业通讯录的企业信息。 |
| 获取部门用户详情（行业通讯录） | 根据部门ID和用户ID，获取部门用户详情。 |
