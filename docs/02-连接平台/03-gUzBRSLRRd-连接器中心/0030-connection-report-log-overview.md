# 概述

本文详细介绍了日志说明和执行动作。

## **简介**

方便管理者了解员工每日工作情况，可以帮助员工总结沉淀工作经验。更多介绍请参见[钉钉使用手册-日志](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/Y7kmbp6NA6NqzLq2?dontjump=true%23%23)。

## **执行动作**

| **执行动作** | **描述** |
| --- | --- |
| 获取模版详情 | 企业可以根据模板名称获取模板详情。 |
| 获取日志评论详情 | 分页获取评论详情，包括评论人userid、评论内容、评论时间。 |
| 获取日志统计数据 | 获取日志统计数据。 |
| 获取用户日志未读数 | 查询企业员工的日志未读数。 |
| 获取日志接收人员列表 | 可获取日志接收人员列表。日志接收范围如果包含群，本接口将会获取到该群内的成员userId值。 |
| 获取日志相关人员列表 | 分页获取日志相关人员列表，包括已读人员列表、评论人员列表、点赞人员列表。 |
| 获取用户发出的日志列表 | 企业可以根据员工userid或者日志模板名称，分页获取员工一段时间范围内在【日志】微应用发送和修改的日志详细信息。 |
| 获取用户可见的日志模板 | 根据用户userId获取当前企业下可见的日志模板列表。 |
| 获取用户发送日志的概要信息 | 企业可以根据员工userid或者日志模板名称，分页获取员工一段时间范围内在【日志】微应用发送的日志概要信息。 |
