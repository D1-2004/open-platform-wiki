# 概述

连接平台提供了QQ、163、阿里云、钉钉四种邮箱连接器，用户可根据需求选取适合的邮箱连接器，发送邮件。

## **连接器**

### **QQ邮箱**

| **执行动作** | **描述** |
| --- | --- |
| 发送邮件 | 以用户设定的QQ邮箱发送邮件 |

### **163邮箱**

| **执行动作** | **描述** |
| --- | --- |
| 发送邮件 | 以用户设定的163邮箱发送邮件 |

### **钉邮**

| **执行动作** | **描述** |
| --- | --- |
| 发送邮件 | 以用户设定的钉钉邮箱发送邮件 |

### **阿里邮箱**

| **执行动作** | **描述** |
| --- | --- |
| 企业邮箱发送邮件 | 以企业管理员设定的阿里云企业邮箱发送邮件 |
| 个人邮箱发送邮件 | 以用户设定的阿里云个人企业邮箱发送邮件 |
