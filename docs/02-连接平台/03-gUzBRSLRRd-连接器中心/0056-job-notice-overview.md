# 概述

## **简介**

工作通知消息是以某个应用的名义推送到员工的工作通知消息，例如生日祝福、入职提醒等。可以发送文本、语音、链接等，消息类型和样例可参考消息类型与数据格式。

在连接平台，你可以使用【工作通知】官方连接器来给员工发送通知，可以是文本、语音、链接、卡片、图片等。

## **场景说明**

### **发送工作通知**

如果需要发送工作通知，可以通过【工作通知】下的执行动作来发送不同类型的通知：

可以通过以下执行动作发送任何类型的工作通知，包括文本、语音、链接、卡片、图片等。由于可以发送所有类型的通知，其参数设置会比较复杂，因此建议通过下面特定场景的工作通知发送。

| **连接器名称** | **执行动作** | **描述** |
| --- | --- | --- |
| 工作通知 | 发送工作通知[文本消息] | 工作通知（文本消息）.png |
| 发送工作通知[图片消息] | 工作通知-图片.png |
| 发送工作通知[markdown消息] | 工作通知-md.png |
| 发送工作通知[整体跳转卡片消息] | 工作通知-整体跳转.png |
| 发送工作通知[横排多按钮ActionCard消息] | 工作通知-横排按钮.png |
| 发送工作通知[竖排多按钮ActionCard消息] | 工作通知-竖排按钮.png |
| 发送工作通知[OA消息] | 工作通知-OA消息.png |
| 发送工作通知[链接消息] | 工作通知-链接消息.png |

### **操作已经发送的工作通知**

工作通知发送后可能需要对工作通知的一些状态进行获取，可以使用【消息通知】连接器下的相应的执行动作：

| **连接器名称** | **执行动作** | **描述** |
| --- | --- | --- |
| 工作通知 | 获取工作通知消息的发送进度 | 查看工作通知消息的发送进度。  **[!NOTE]**  只能获取24小时内工作通知消息的发送进度。 |
| 更新工作通知状态栏 | 针对消息类型为OA消息，调用本执行动作可以更改OA消息状态栏。  **[!NOTE]**  只能更新24小时内发出的OA工作通知状态栏。 |
| 撤回工作通知消息 | 本执行动作可以撤回工作通知消息。  **[!NOTE]**  只能撤回24小时内发送的工作通知消息。 |
| 获取工作通知消息的发送结果 | 本执行动作可以获取哪些员工没有发送成功，以及没有成功的原因。  **[!NOTE]**  只能获取24小时内工作通知消息的发送结果。 |
