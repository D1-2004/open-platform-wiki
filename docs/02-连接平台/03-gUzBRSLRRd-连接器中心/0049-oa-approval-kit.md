# 套件

本文介绍了OA审批获取套件信息及常用套件信息展示。

## **流程简介**

> **[!NOTE]**
>
> 以下套件审批集成连接器, 均不支持。高阶版连接器, 支持以下套件的读操作。

连接平台获取套件信息操作：

1. 创建业务流。
2. 触发事件中选择官方连接器—审批。
3. 触发事件中选择触发事件—实例（高阶版）。
4. 配置参数中选择流程表单—OA审批。
5. 具体表单选择，需要获取套件信息的表单。

> **[!NOTE]**
>
> 如果找不到需要获取套件信息的表单，表示该表单信息无法被获取。

可以通过查看出参，获取表单套件字段信息：
