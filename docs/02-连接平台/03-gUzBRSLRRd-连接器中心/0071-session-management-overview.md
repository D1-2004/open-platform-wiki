# 概述

## **简介**

会话管理是钉钉通过开放多样的方式根据业务的需要创建、设置和管理群以及群内的成员，还可以为用户提供基于具体业务场景下的群内服务，将沟通和协同融合起来，让组织成员在群聊中通过丰富的群能力实现高效的、结构化的、明确的协作和沟通，提高协同办公效率。
