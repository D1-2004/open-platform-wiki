# 流程变量

## **简介**

在编排流程的过程中，你可能需要对特定流程节点的输入参数和输出参数进行操作，或者你需要定义一个临时变量以便于后续的操作。**流程变量**功能为你提供了这种灵活且便捷的处理能力。你可以根据具体业务需求，创建所需的流程变量，并在之后的流程中使用或更新定义的变量。

## **能力说明**

**流程变量**提供了创建基本类型变量、更新基本类型变量、创建对象类型变量和更新对象类型变量执行动作。

> **[!NOTE]**
>
> 流程变量具有限定的使用范围，即它们的作用域是局部的：
>
> - 如果流程变量是在主流程中创建的，那么它可以被主流程中后续的所有节点所使用。
> - 如果流程变量是在一个分支内创建的，那么它仅能在该分支内被使用。
> - 如果流程变量是在循环结构中创建的，那么它只能在当前的这个循环中使用。

### **创建基本类型变量**

创建基本类型的变量，预设在流程中使用的值。

#### **入参配置**

| **配置项** | **类型** | **必填** | **描述** |
| --- | --- | --- | --- |
| **变量组** | Array | — | 变量组中可创建多个变量，可通过单击**新增变量**向变量组添加新的变量。 |
| **变量key** | String | 是 | 变量编码，不能与其他变量同名，保证编码唯一。 |
| **变量名称** | String | 否 | 变量名称，后置节点中显示该名称。不输入则默认为变量编码。 |
| **变量类型** | String/Number/Boolean | 否 | 变量类型，默认为String类型。 |
| **默认值** | String/Number/Boolean | 是 | 变量的默认值。 |

#### **出参配置**

| **配置项** | **类型** | **描述** |
| --- | --- | --- |
| **变量组** | Object | 出参为所有变量的键值对。 |
| **变量key** | String/Number/Boolean | 创建时设置的变量值。 |

### **更新基本类型变量**

更新基本类型的变量，后置流程节点将获取到更新后的值。

### 创建对象类型变量

创建Object类型的变量，变量各字段可引用前置节点的出参值，或自定义输入值。后置节点可以获取该变量的任意字段值。

#### **入参配置**

| **配置项** | **类型** | **必填** | **描述** |
| --- | --- | --- | --- |
| **变量key** | String | 是 | 变量编码，不能与其他变量同名，保证编码唯一。 |
| **变量名称** | String | 否 | 变量名称，后置节点中显示该名称。不输入则默认为变量编码。 |
| **变量初始值** | Object | 是 | Object类型变量，通过单击**设置变量结构**按钮，进行自定义设置。 |

#### **出参配置**

| 配置项 | 类型 | 描述 |
| --- | --- | --- |
| 变量值 | Object | 变量结构与入参中设置的结构一致，在后置节点可以引用该变量任意字段的值。 |

### 更新对象类型变量

更新Object类型的变量，后置流程节点将获取到更新后的值。
