# 概述

## **简介**

AI接口是由阿里巴巴达摩院提供的功能服务，用于提升企业办公效率，主要有以下两个使用场景。

## **执行动作**

| **执行动作** | **描述** |
| --- | --- |
| 文本翻译 | 输入一段文本，得到翻译指定语言后的译文，支持多种语言的互译。 |
| OCR文字识别 | 根据识别图片地址，进行OCR文字识别。 |
