# 循环控制

## **简介**

在你的流程操作中，如果引入了循环节点去处理特定业务逻辑，并且希望在循环过程中能够在满足特定条件时提前结束整个循环或跳过当前的循环迭代，你可以借助**循环控制**工具来实施精确的循环操作控制。

## **能力说明**

循环控制包含**终止循环**和**跳出循环**两个执行动作。

- 终止循环：立即结束本次循环，并终止后续循环。其作用同循环控制语句 break。
- 跳出循环：立即结束本次循环，并继续后续循环。其作用同循环控制语句 continue。
