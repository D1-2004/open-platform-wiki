# 概述

## **简介**

待办是钉钉的一个协同办公产品，帮助企业员工更高效的进行事项（工作任务）管理。钉钉待办提供了强大的开放能力，各类业务系统或企业自建应用可低成本的接入。更多介绍请查看[钉钉产品使用手册-待办](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/Y7kmb7Dd340Y3GLq?dontjump=true%23%23)。
