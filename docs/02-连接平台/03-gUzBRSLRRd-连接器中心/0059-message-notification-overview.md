# 概述

## **简介**

消息通知是以企业的名义推送到企业内部群，例如生日祝福、入职提醒等。可以发送文本、语音、链接等。

在连接平台，你可以使用【消息通知】官方连接器来给员工发送通知，可以是文本、语音、链接、卡片、图片等。
