# 概述

## **简介**

钉钉智能人事提供了强大、灵活、安全的人事解决方案，让企业迅速建立起来员工花名册，搭建员工入职、转正、调岗、离职流程，并给员工良好的使用体验。

在连接平台，你可以使用【智能人事】连接器完成组织内部人员花名册数据的查询和更新。

## **场景说明**

### **触发事件**

| **连接器名称** | **触发事件** | **描述** |
| --- | --- | --- |
| 智能人事 | 人事档案变动 | 监听事件：   - 人事平台员工异动 - 人事平台员工档案变动事件相关数据事件 - 人事解决方案变更事件 - 人事商业化方案事件 - 培训学习记录同步事件   **[!NOTE]**  当组织内部发生人事相关信息的变动时，可以通过【智能人事】下的触发事件【人事档案变动】来对事件进行监听。 |

### **执行动作**

#### **花名册数据管理**

智能人事花名册是组织在钉钉上记录的有关人力资源存档备查的档案，包括系统信息，基本信息，工作信息，个人信息，学历信息，银行卡信息，合同信息，紧急联系人信息，家庭信息，个人材料等。

| **连接器名称** | **执行动作** | **描述** |
| --- | --- | --- |
| 智能人事 | 获取花名册元数据 | 获取员工花名册的元数据定义。  **[!NOTE]**  包括花名册分组、字段定义。 |
| 获取员工花名册字段信息 | 获取员工花名册字段信息。 |
| 获取花名册字段组详情 | 提供给ISV查询花名册的员工档案信息中有权限的字段列表。 |
| 更新员工花名册信息 | 更新员工花名册信息。 |

#### **员工管理**

组织内部员工状态可以分为：待入职，在职，离职等：

- 对于待入职员工，可以添加待入职的信息。
- 对于在职员工，可以查询在职员工的列表信息
- 对于离职员工，可以查询离职员工的列表信息，离职员工的离职详情，修改员工的离职信息。

| **连接器名称** | **执行动作** | **描述** |
| --- | --- | --- |
| 智能人事 | 添加企业待入职员工 | 智能人事添加待入职员工信息。 |
| 获取待入职员工列表 | 智能人事业务，企业/ISV分页查询公司待入职员工id列表。 |
| 获取在职员工列表 | 能人事业务，提供企业/ISV按在职状态分页查询公司在职员工id列表。 |
| 获取离职员工列表 | 查询企业离职员工userId列表。 |
| 获取离职员工的信息 | 根据传入的userid列表，批量查询员工的离职信息。  **[!NOTE]**  如果传入为非离职员工userid，不会返回信息。 |
| 修改员工最后一次离职信息 | 修改智能人事中已离职员工的信息。  **[!NOTE]**  支持修改离职员工的最后工作时间和离职备注信息。 |
