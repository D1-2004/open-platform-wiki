# 用量统计

## **介绍**

用量统计提供连接流按月维度的执行汇总视图，帮助开发者掌握额度消耗节奏、识别用量异常波动、定位高频/低成功率连接流，为容量规划与成本管控提供数据支撑。

选择目标月份后，页面展示以下四个模块：**实际用量统计、消耗趋势、连接流执行明细、Top10 高频流排行**。

> ***注意****：汇总统计数据采用 T+1 累计口径，当日数据需次日方可查看。*

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0506584871/p1090386.png)

## **实际用量统计**

展示当前月份的额度使用情况，包含三项核心指标：

| 字段 | 说明 |
| --- | --- |
| 本月使用额度 | 截至当前已消耗的节点执行次数。 |
| 本月总额度 | 当前套餐对应的月度可用上限。 |
| 本月剩余额度 | 总额度减去已使用额度。 |

**额度规则**：

- **钉钉专业版**：300,000 次/月
- **专业版到期后自动降级**：8,000 次/月

当剩余额度接近耗尽时，建议及时升级套餐或排查是否存在异常调用导致额度快速消耗。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0506584871/p1090392.png)

## **消耗趋势**

以折线图形式展示当月每日的连接流节点执行量变化，支持直观识别用量峰值与低谷。

> **[!NOTE]**
>
> 汇总统计采用的是T+1累计指标，需要第二天才能看到前一天的数据。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0506584871/p1090393.png)

**图表说明**：

- **横轴**：当月日期（如 20260701 ~ 20260727）
- **纵轴**：当日节点执行次数
- **蓝色折线**：连接平台触发的执行量
- **橙色折线**：文档（多维表）等其他场域触发的执行量

**典型分析场景**：

- **突增尖峰**：对应某日有批量任务触发或定时流集中执行，可结合「连接流执行明细」定位具体流名称。
- **持续高位**：可能存在循环调用或未设限时的流被高频触发，需检查流逻辑是否合理。
- **长期低位**：该月整体业务调用量少，若预期应有更高用量，需排查触发条件是否正常生效。

## **连接流执行明细**

以表格形式列出当月所有连接流的执行汇总数据，支持按来源、创建者、流名称进行筛选，并提供报表导出能力。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0506584871/p557407.png)

### 字段说明

| 字段 | 说明 |
| --- | --- |
| 序号 | 列表行号。 |
| 流名称 | 连接流名称，收费流以橙色「收费流」标签标识。 |
| 所属场域 | 触发来源（如「连接平台」「文档（多维表）」「IM 场域」等）。 |
| 所属空间 | 连接流所在的工作空间。 |
| 创建者 | 该连接的创建人姓名。 |
| 最后修改时间 | 流最近一次编辑的时间戳。 |
| 流执行量 | 该流被触发的总次数。 |
| 节点执行量 | 该流所有节点执行的累计次数（含重试）。 |
| 成功率 | 成功执行次数 / 流执行量 × 100%。 |
| 操作 | 「已启用 / 停用」状态切换按钮。 |

### 筛选与导出

- **所有来源下拉框**：按触发场域过滤，快速聚焦某一入口的流执行情况。
- **搜索创建者**：输入姓名关键字，定位特定开发者名下的连接流。
- **搜索流程名称**：输入流名称关键字，精确查找目标流。
- **导出报表**：将当前筛选结果导出为文件，便于离线分析或归档汇报。

## **常见问题**

汇总统计采用 T+1 累计口径，当日数据将在次日凌晨完成聚合后展示。如需实时监控单次执行详情，请使用「执行记录」页面。

- **如何排查消息发送成功率偏低的问题？**

  1. 在「连接流执行明细」中按成功率升序排序，定位低成功率流。
  2. 点击该流进入「执行记录」，筛选失败状态，查看具体失败原因。
  3. 结合失败原因（如 API 超时、参数校验不通过、权限不足等）针对性修复。
- **额度耗尽后会怎样？**

  当月额度用尽后，新触发的连接流执行将被拦截并返回额度不足错误。建议设置额度告警阈值，或在用量趋势出现异常增长时提前介入排查。
