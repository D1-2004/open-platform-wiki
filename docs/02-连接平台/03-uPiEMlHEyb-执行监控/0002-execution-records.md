# 执行记录

## **介绍**

执行记录是钉钉连接平台提供的连接流运行监控与排查工具，用于查看连接流的每次执行详情、追踪节点执行情况、定位失败原因，并支持对失败任务进行重试操作。

## **核心能力**

### 多维度筛选查询

- **时间范围筛选**：支持自定义起止时间（精确到秒），最多可追溯历史数据。

  > **[!NOTE]**
  >
  > 最多可查看一个月内的执行记录。
- **执行状态筛选**：按「成功」「失败」等状态快速过滤，便于聚焦异常记录。
- **来源筛选**：按触发来源（如「连接平台」「文档（多维表）」「IM 场域」「直播」等）分类查看。

### 列表字段说明

| 字段 | 说明 |
| --- | --- |
| 流名称 | 连接流的名称，收费流会以橙色标签标识。 |
| 流版本 | 当前执行所使用的流版本号（如「版本5」「版本9」）。 |
| 节点执行量 | 本次执行中实际触发的节点数量。 |
| 来源 | 触发该次执行的入口来源。 |
| 触发时间 | 执行被触发的具体时间（格式：YYYY-MM-DD HH:mm:ss）。 |
| 耗时 | 从触发到结束的总耗时（单位：毫秒）。 |
| 执行状态 | 蓝色圆点表示成功，红色圆点表示失败。 |
| 失败原因 | 仅失败记录显示，简要描述错误信息（如「远程 API 调用失败」「参数校验不通过」等）。 |
| 操作 | 提供查看详情、复制 ID、重试等操作入口。 |

### 操作说明

- **查看详情**：点击可查看该次执行的完整节点链路、输入输出参数、各节点耗时等详细信息。
- **复制 ID**：一键复制本次执行的唯一标识 ID，便于在日志或工单中引用。
- **重试**：针对失败记录，支持下拉展开重试选项，可选择重新执行整条流或指定节点。

## 使用场景

- **日常巡检**：通过时间 + 状态组合筛选，快速确认近期是否有异常执行。
- **故障排查**：点击失败记录的「查看详情」，定位具体出错节点及原因。
- **问题复现**：复制执行 ID 后提交工单，协助技术支持快速定位问题。
- **批量重试**：对已知临时性故障（如网络抖动导致的 API 超时）的失败记录执行重试。

## **如何查看执行记录**

### **方式一：执行记录直接查看**

针对具体的执行记录可以进行**查看详情**和**复制ID**操作，针对失败的流可以进行重试。如下图所示：

> **[!NOTE]**
>
> - **监控中心 > 执行记录**中为所有连接流的执行记录，查看详情操作。
> - 最多可查看一个月内的执行记录。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2134735871/p557410.png)

### **方式二：在连接流中查看**

1. 在**我的连接流**中，找到目标连接流，依次**点击更多 > 执行记录**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2134735871/p1090856.png)
2. 在连接器详情中的**执行记录**，可查看当前连接流的执行记录信息。

   > **[!NOTE]**
   >
   > 最多可查看一个月内的执行记录。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2134735871/p1090857.png)

## 注意事项

- 「收费流」标签标识该连接流为付费资源，执行时会消耗对应配额。
- 通过时间筛选执行记录时，只支持筛选近一个月内的数据。
- 重试操作会生成一条新的执行记录，原失败记录仍保留在列表中。
- 分页默认为每页 10 条，可通过底部翻页控件浏览更多历史记录。
