# 介绍

## **简介**

​考勤自动化，旨在帮助用户**将考勤数据和不同的应用打通**，实现工作流程的自动化。

**🕒** 自动通知指定用户/群，让管理无死角

🔧 考勤结果动态监控，即时更新

👥 智能化团队联动，提升协作效率

## **实现场景**

## **考勤自动化入口**

> **[!NOTE]**
>
> 只有考勤管理员才能使用考勤自动化功能，仅支持在电脑端钉钉使用。

1. 工作台中，单击**考勤打卡**应用。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8683735071/p758046.png)
2. 单击**考勤自动化**，选择一个模板创建流程，或从空白创建流程。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8683735071/p758047.png)
