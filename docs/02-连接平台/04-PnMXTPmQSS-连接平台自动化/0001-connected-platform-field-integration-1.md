# 概述

## **为什么要使用自动化**

连接平台通过组件化方案，帮助钉钉用户在官方应用内直接获得自动化和集成能力，助力企业降本增效。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1573735071/p758385.png)

## **什么是自动化流程**

连接平台通过自动化流程，将**多个系统或应用**串在一起进行**自动通信和协作**。一个自动化流程，可以理解为**“如果发生 A 情况，就执行 A 操作”**。例如下图，其含义为“如果到达了规定的时间，就发送机器人消息到该群组”。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1573735071/p753402.png)

## **群聊自动化**

群聊自动化通过自动化小助手在群聊中，不同的群成员可以创建多条不同的自动化流程，**将日常重复的工作自动化，降低人力成本，提高工作效率**。详情参考[群聊自动化](0003-introduction.md)。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1573735071/p758396.png)

## **考勤自动化**

考勤自动化，旨在帮助用户**将考勤数据和不同的应用打通**，实现工作流程的自动化。比如考勤打卡自动通知指定用户/群，让管理无死角；考勤结果动态监控，即时更新等。详情参考[考勤自动化](0010-attendance-introduction.md)。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1573735071/p758390.png)

## **多维表自动化**

多维表自动化，通过将**多维表数据的变化自动同步给其他应用**，从而降低人力成本，**提高数据同步的效率和准确性**。多维表自动化广泛应用于日常工作场景，如项目管理、客户服务、团队提效、流程管理等。详情参考[多维表自动化](0012-multidimensional-introduction.md)。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2573735071/p758387.png)

## **用量统计**

**自动化**服务由**钉钉连接平台**提供，该服务的用量——**连接流节点执行量，**统计了当前组织在多维表、机器人、OA审批、连接平台等场域的节点执行量总和，获得开发权限的用户可以到钉钉连接平台[查看数据详情](https://open-dev.dingtalk.com/fe/connector#/overView)，计量规则可参考[钉钉连接平台计费模型](../01-6Ar2XD4H6b-平台介绍/0002-connection-platform-billing-model-1.md)。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9759964071/p755093.png)
