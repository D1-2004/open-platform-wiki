# 创建连接器

在官方连接器和第三方连接器均无法满足企业的自动化流程或集成需求时，您也可以通过自建连接器来连接企业自建系统，实现业务自动化处理。

## **前提条件**

完成[成为钉钉开发者](https://open.dingtalk.com/document/dingstart/dingtalk-developer)的流程。

## **操作步骤**

1. 登录[开发者后台](https://open-dev.dingtalk.com/)。
2. 单击**开放能力 > 连接平台> 我的连接器 > 创建连接器**。输入相关信息后，单击确定创建。

   | **配置项** | **说明** |
   | --- | --- |
   | 连接器名称（必填） | 请输入连接器名称 |
   | 连接器描述 | 请输入连接器描述 |
   | 关联应用 | 请选择本组织在开放平台上架的应用 |
3. 创建完成后，进入连接器基本信息页面。如果你需要编辑连接器信息，可以单击右上角**编辑**按钮。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3743786071/p766129.png)

   > 如果你需要了解连接器的高级设置能力，请参考[高级功能](https://open.dingtalk.com/document/connector/overview)。

## 后续步骤

连接器创建完成后，你可以针对连接器：

- [添加触发事件](0014-add-trigger-event-1.md)
- [添加执行动作](0015-add-execution-action-1.md)

> 如果你的执行动作需要鉴权，请参考[概述](0027-connection-overview.md)概览。
