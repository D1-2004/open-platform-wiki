# 连接凭证

本文介绍钉钉连接平台中连接凭证的含义及连接凭证模块主要功能。

## **什么是连接凭证**

- 连接凭证是调用该连接器时，该连接器所需要的所有参数，连接器需要通过这些参数来建立连接。一个连接器可拥有多个连接凭证，在不同的场景或者不同的调用方选择不同的连接凭证进行建立连接。
- 连接凭证包含了当前连接器的鉴权值及模板参数。

## **为什么使用连接凭证**

连接凭证模块可管理所有连接器所需要的连接凭证，对连接凭证进行增删改查。
