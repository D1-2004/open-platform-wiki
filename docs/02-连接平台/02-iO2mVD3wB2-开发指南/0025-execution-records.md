# 执行记录

## **执行记录**

执行记录提供了对连接流执行记录的查看，可以通过操作1进行选择具体日期、执行记录状态、业务类型进行组合查询。针对具体的执行记录可以进行**查看详情**和**复制ID**操作，针对失败的流可以进行重试。如下图所示：

> **[!NOTE]**
>
> **监控中心 > 执行记录**中为所有连接流的执行记录，查看详情操作，请参见[执行记录](https://open.dingtalk.com/document/connector/execution-records-1)。
