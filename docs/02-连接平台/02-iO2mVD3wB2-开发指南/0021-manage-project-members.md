# 管理项目成员

如果你需要添加项目协同成员，你可以参考本文档操作步骤完成添加操作。

## **前提条件**

完成[创建连接项目](https://open.dingtalk.com/document/connector/create-a-connection-project)流程。

## **操作步骤**

1. 登录开发者后台，单击**开放能力** > **连接平台**。
2. 单击**配置中心** > **连接项目 > 目标连接项目，进入项目详情页。**
3. 单击**成员信息**，配置项目成员**。**

   | **成员** | **描述** |
   | --- | --- |
   | 项目管理员 | 具有项目成员的所有权限，还具有新增删除项目成员的权限。无创建项目和删除项目权限。 |
   | 项目成员 | 具有项目关联的连接器、连接流的操作权限。 |
