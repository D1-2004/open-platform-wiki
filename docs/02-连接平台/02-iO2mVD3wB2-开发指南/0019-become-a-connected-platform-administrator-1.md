# 成为连接平台管理员

如果你需要创建连接项目或者删除连接项目，你需要成为连接平台管理员，你可以参考本文档操作步骤成为连接平台管理员。

## **管理员添加连接平台管理员**

1. 登录[钉钉管理后台](https://open.dingtalk.com/document/orgapp/obtain-developer-permissions)，单击左侧导航栏**安全与权限**>**权限管理**>**子管理员**>**添加子管理员。**

2. 在**配置权限** > **钉钉官方应用权限**中，单击设置，并添加**工作台与应用开发** > **连接平台管理权限**。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4115100071/p737801.png)

## **开发者主动申请连接平台****管理权限**

1. 打开钉钉客户端，单击**工作台** > **OA审批**。
2. 搜索**子管理员权限申请**审批单。
3. 申请**连接平台管理权限，**并提交审核。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3115100071/p737812.png)
