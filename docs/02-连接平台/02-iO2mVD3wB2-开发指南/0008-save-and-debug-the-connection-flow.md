# 保存并调试连接流

完成连接流配置后，可以保存连接流，并对连接流进行调试。本文将介绍如何保存并调试连接流。

## **前提条件**

完成[编排流程](0003-orchestration-process-overview.md)。

## **操作步骤**

1. 单击**保存草稿**，保存已经完成创建的连接流。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8643786071/p762295.png)
2. 单击**调试**按钮，跳出连接流调试界面，调试的输入字段为连接流中触发事件的入参。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9643786071/p762296.png)
3. 输入对应入参字段值，点击确定即可发起调试。如果流程调试成功，所有节点将显示为 ✓ 运行正确。

## **后续步骤**

调试成功后，你需要[发布连接流](0009-publish-connection-flow.md)。
