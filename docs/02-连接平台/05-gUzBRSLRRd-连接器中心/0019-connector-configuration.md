# 连接器配置

## 前提条件

在开始本教程前，确保你已经完成了以下准备工作：

- 已经成为钉钉专业版用户，若未完成，请参考[钉钉专业版](dingtalk://dingtalkclient/page/link?url=https%3A%2F%2Fn.dingtalk.com%2Fdingding%2Fdd-pro-composite-order%2Fpc%2Findex.html%3Fpopup_wnd%3Dtrue%26dd_tab%3Dtrue%26width%3D900%26height%3D600%26title%3D%25E9%2592%2589%25E9%2592%2589%25E6%2595%25B0%25E5%25AD%2597%25E8%25B5%2584%25E4%25BA%25A7%26articleCode%3DDT_GOODS_dingtalkmemberplus%26channel%3Dopenpf_web_devdoc%26corpId%3D${corpId}%26accessoryProduct%3DpaasWithConnector%26tabKey%3DDT_GOODS_dingtalkmemberplus&popup_wnd=true&height=600&width=900)。
- 已经完成了钉钉开发者的注册与激活并拥有了子管理员和开发者权限。若尚未完成，请参考[成为钉钉开发者](https://open.dingtalk.com/document/dingstart/dingtalk-developer)。

## 操作步骤

### 步骤一：系统集成

1. **进入OA审批管理后台**

   依次选择**工作台 > OA审批**，然后选择**管理后台**。

   ![OA审批-连接器配置-进入OA审批管理后台](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4842009661/p521902.png)
2. **模板中心**

   在**OA审批管理后台**界面，依次选择**系统集成 > 模板中心**，展示当前企业所有可用的**官方连接器**和**三方连接器**。

   ![连接器配置-模板中心 ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4842009661/p507395.png)
3. **我的集成**

   在**OA审批管理后台**界面，依次选择**系统集成 > 我的集成**，展示当前企业所有自建的连接器。

   ![我的集成](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4842009661/p409517.png)
4. **创建自建连接器**

   单击**新建连接器**，可进入连接平台后台创建自建连接器。

   > **[!NOTE]**
   >
   > ​如何创建自建连接器，详情请参考[创建连接器](../02-XdgyZifJkr-我的连接/0010-create-connector.md)、[添加触发事件](../02-XdgyZifJkr-我的连接/0011-add-trigger-event-1.md)、[添加执行动作](../02-XdgyZifJkr-我的连接/0012-add-execution-action-1.md)。

   ![OA审批-连接器配置-选择新建连接器](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4842009661/p521927.png)

### 步骤二：配置表单

1. **创建新表单**

   在**OA审批管理后台**界面，依次选择**表单管理 > 创建新表单**，然后选择**流程表单。**

   ![表单管理](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4842009661/p409502.png)
2. **表单配置连接器**

   在**表单设计**界面，选择**连接器**，然后单击**配置连接器**。![配置连接器](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1134956661/p409519.png)
