# 大纲树面板

通过本文你可以了解到如何使用大纲树面板来协助你更好的开发卡片模板。

## **一、内容介绍**

通过大纲树面板，你可以清晰地看到当前卡片模板使用的所有组件的**层级结构**，同时还可以在大纲树中快速选中组件并拖拽进行**布局调整或重命名**等操作，大纲树面板入口如下：

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6046989661/p514982.png)

## **二、查看组件层级结构**

大纲树与模拟器中的组件是一一对应的，当你在大纲树中选中一个组件时，模拟器对应的组件区域就会进行高亮，反之亦然。此时打开大纲树面板便可以看到该选中组件的层级结构了。如图，该「图片」组件的层级为：**卡片 > 布局容器 > 布局 > 图片**

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6046989661/p513847.png)

## **三、快速调整布局**

如上所述，在大纲树中，单击组件可以对应地在模拟器中进行高亮，而如果长按组件，则可以对某个组件进行拖拽，通过拖拽可以快速的调整布局，如图所示：

![drag_component_tree](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6262293761/p536847.gif)

## **四、组件重命名**

在大纲树中双击组件名称即可进入编辑状态，对组件进行重命名。当大纲树较为复杂时重命名可以让你的大纲树更加清晰。具体操作如图所示：

![com_name_edit](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7262293761/p536813.gif)
