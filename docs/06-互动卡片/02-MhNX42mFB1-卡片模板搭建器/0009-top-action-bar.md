# 顶部操作栏

通过本文你将了解到搭建器顶部操作栏的所有功能以及使用方法。

## **一、内容介绍**

卡片搭建器顶部的操作栏主要提供了一些卡片模板级别的操作，如模板的导入、导出、复制以及保存和发布等功能，同时在操作栏上也显示了卡片模板的名称、内容更新的保存情况以及帮助入口相关的信息。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7982293761/p516388.png)

## **二、功能介绍**

### **1. 复制模板**

填写新模板的名称并确认，即可在模板列表中创建当前模板的副本。

### **2. 导出**

导出当前模板所有信息的 JSON 描述文件，可以导入到其他模版文件中使用。

### **3. 导入**

可以导入 **通过“导出”功能获取的 JSON 描述文件**，在当前卡片模板中使用。

### **4. 保存**

保存当前卡片模板的所有修改。

### **5. 发布**

当开发者充分测试卡片模版功能并确认无误后，可以发布并锁定当前卡片模板，避免对模板的意外修改，导致不可预知的业务异常。

> **[!IMPORTANT]**
>
> 模板一旦发布则无法再次编辑，请谨慎操作。
