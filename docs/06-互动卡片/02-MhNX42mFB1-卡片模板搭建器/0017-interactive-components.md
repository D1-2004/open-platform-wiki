# 交互组件

本文介绍互动卡片所有支持交互的组件列表，以及交互的优先级。

## **支持交互的组件**

| **组件** | | **交互方式** |
| --- | --- | --- |
| 卡片 | | 通用交互方式，详见[交互方式](0016-interactive-mode.md)。 |
| 基础组件 | 链接 | 通用交互方式，详见[交互方式](0016-interactive-mode.md)。 |
| 横排/竖排按钮 | 通用交互方式，详见[交互方式](0016-interactive-mode.md)。 |
| 布局/布局容器 | 通用交互方式，详见[交互方式](0016-interactive-mode.md)。 |
| 图表 | 点击之后打开图表详情页面。可自由配置是否启用该交互能力 |
| 图片/多图 | 点击之后打开钉钉的图片预览窗口进行图片预览。可自由配置是否启用该交互能力 |
| 视频 | 点击之后打开独立的视频播放器窗口播放视频或直接在卡片内部进行播放。可自由配置是否启用内播能力。 |
| 轮播图 | 点击之后打开钉钉的图片预览窗口进行图片预览。可自由配置是否启用该交互能力 |
| 选择框 | 更新本地变量或发送回传请求 |
| 区块组件 | 按钮 | 通用交互方式。 |
| 图片/多图 | 点击之后打开钉钉的图片预览窗口进行图片预览。可自由配置是否启用该交互能力 |
| 视频 | 点击之后打开独立的视频播放器窗口。暂不支持关闭 |
| 轮播图 | 点击之后打开钉钉的图片预览窗口进行图片预览。可自由配置是否启用该交互能力 |
| 时间选择器/文本+时间选择器 | 点击之后打开时间选择器控件 |
| 聚合菜单/文本+聚合菜单 | 点击之后打开弹出聚合菜单 |
| 多选下拉框/文本+多选下拉框 | 点击之后打开多选下拉框 |
| 下拉框/文本+下拉框 | 点击之后打开单选下拉框 |

## **不支持交互的组件添加交互**

从上面的表格可以看出，不是所有的组件都支持交互。如果希望在不支持交互的组件里面添加一些交互能力，那么就可以通过布局嵌套的方式来实现，即把所需要添加交互能力的组件放置在“布局容器”组件里面，由布局组件来提供交互能力。

如下图，如果希望点击每一篇文章都能打开链接，那么就可以把文章标题和文章图片放置在布局容器内，同时给布局容器设置点击事件。

## **交互优先级**

由于卡片里面可以通过布局容器来进行嵌套，那么可能会出现同个位置有多个交互逻辑，当出现交互重叠时，这时卡片会按照一定的优先级来执行交互逻辑：**子节点的交互优先级要高于父节点，且只会响应最深的子节点，其余父节点交互逻辑均不会执行。**

例如在上图的例子中，假设给布局容器添加链接跳转的交互之外，还给布局容器里面的图片添加了可预览的交互，那么在实际运行时，点击图片区域，会打开图片的预览功能，这时不会发生链接跳转。而如果点击的是图片左边的文字的话，那么会直接进行链接跳转。核心原因是图片的交互逻辑（子节点）优先级要高于布局容器的交互逻辑（父节点）。
