# 交互方式

本文介绍钉钉互动卡片所具备的交互方式，以及具体的使用方法。

## **卡片添加交互**

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0292293761/p550668.png)

钉钉互动卡片具备互动能力，可以通过给按钮等交互组件添加点击事件即可。以按钮为例，在按钮的设置项里面，通过配置“按钮点击事件类型”即可为按钮添加交互能力。

## **交互方式列表**

| **交互方式** | **作用** | **配置项** | | **备注** |
| --- | --- | --- | --- | --- |
| **链接跳转** | 点击之后打开一个链接 | 链接类型 | 用来指定当前链接是否需要区分不同客户端。如果所需要跳转的页面不需要设置不同端使用不同链接，那么使用“统一链接”即可 | 如果希望链接在钉钉客户端内以侧边栏/半浮层的方式打开，那么请参考[链接跳转规范](../04-zGou6m9pee-卡片规范设计/0002-link-jump-specification.md)。 |
| 链接值 | 所需要打开的链接地址。可以是一个固定的链接，也可以绑定一个变量。  **必填，如果值为空，则点击无响应** |
| 是否 dtmd 链接 | 当前链接是否是一个 dtmd 协议的链接。如果所配置的链接是以 dtmd:// 协议开头的，那么需要开启该选项，否则 dtmd 协议不生效 |
| **回传请求** | 点击之后发起一个回调请求到回调地址上 | 回传参数 | 用来指定当前回调请求的一些相关上下文参数，比如对于一个点赞请求，可以在参数里面配置一个 like 参数，值可以配置固定值或绑定变量。  当业务接收到回调请求后，能够解析到所携带的相关参数 | 回传请求的具体请求内容为：   ``` {     "corpId": "dingXXXXXX",     "outTrackId": "XXXXXX",     "userId": "XXXXXX",     "value": "{\"cardPrivateData\":{\"actionIds\":[\"1\"]},\"params\":{\"like\":\"true\"}}" } ```   其中value字段为卡片的请求上下文，里面包含了当前按钮的 id ，即 actionIds ，同时包含请求的参数，即 params |
| 请求成功 Toast 文案 | 当请求成功之后，客户端所弹的 toast 文案内容 |
| 请求失败 Toast 文案 | 当请求失败之后，客户端所弹的 toast 文案内容 |
| 请求成功判定条件 | 用来让开发者指定当前业务如何判断请求是否成功。  只有配置了该配置项，上述的请求成功/失败文案才能正常显示。 |
| **复制内容** | 点击之后复制指定的文字内容 | 复制内容 | 所要复制的文本内容。可以使用变量 |  |
| **确认框** | 点击之后弹出一个二次确认弹窗 | 确认框标题 | 二次确认弹窗的标题。支持使用变量，以及支持多语言配置 | 确认框具体效果如下：  PC 端效果：  image  移动端效果：  image |
| 确认框内容 | 二次确认弹窗的内容。支持使用变量，以及支持多语言配置 |
| 确认按钮文案 | 二次确认弹窗中的确认按钮的文案。支持使用变量，以及支持多语言配置 |
| 确认按钮点击事件类型 | 二次确认弹窗中确认按钮点击之后所要触发的动作。如“回传请求” |
| 确认按钮回传参数 | 当确认按钮的事件类型为“回传请求”时所需要设置的请求参数 |
| 取消按钮文案 | 二次确认弹窗中的取消按钮的文案。支持使用变量，以及多语言配置 |
| 取消按钮点击事件类型 | 二次确认弹窗中取消按钮点击之后所要触发的动作 |
| 取消按钮回传参数 | 当取消按钮的事件类型为“回传请求”时所需要设置的请求参数 |
| **动作面板** | 点击之后弹出一个动作面板，即 Actionsheet | 动作面板标题 | 动作面板的标题。非必填 | 动作面板具体效果如下：  PC端效果：  image  移动端效果：  image |
| 动作面板描述 | 动作面板的描述。非必填 |
| 动作列表 | 动作面板里面的选项。需要在搭建器上枚举出来，暂不支持动态的动作列表 |
| 样式类型 | 动作选项的样式，目前有两种样式类型：   - 默认样式 - 警告样式   其中，警告样式会以红色字进行展示 |
| 动作名称 | 动作选项的文案内容 |
| 动作描述 | 动作选项的描述内容。非必填 |
| 动作类型 | 点击当前动作之后所触发的事件。目前可以配置“打开链接”或“回传请求” |
| **弹窗提示** | 点击之后弹出一个提示，即 Toast 提示 | 提示内容 | 所要显示的 toast 文案内容 |  |
| 提示类型 | Toast 提示的类型，目前有三种：   - 默认 - 成功 - 失败   这三者区别在于 toast 提示的 icon。  **目前只在 PC 端中生效** |
