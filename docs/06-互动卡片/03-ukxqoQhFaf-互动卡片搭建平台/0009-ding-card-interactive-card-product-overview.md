# 概述

本文介绍了互动卡片普通版产品、开放的接口能力，如何使用互动卡片普通版等内容。

## 什么是互动卡片普通版

[钉钉互动卡片](0001-platform-building-overview.md)是一种新型的消息类型，它具有动态性、可交互性、多端统一等特点。它能够极大地丰富消息类型，并且促进用户的沟通互动。

## 什么是互动卡片普通版搭建平台

[**互动卡片普通版搭建平台**](https://card.dingtalk.com/card-builder)是钉钉提供的一套开箱即用的卡片解决方案，它提供了丰富的组件来满足复杂的样式需求，开发者无需再从零开始搭建卡片模板。开发者在接入开发互动卡片前，需要先使用[互动卡片普通版搭建平台](https://card.dingtalk.com/card-builder)创建互动卡片模板。

| 机器人发送互动卡片 | 机器人发送互动卡片消息，支持单聊和群聊。 | [机器人发送互动卡片（普通版）](../../01-应用开发/02-4a8AMF6u2A-服务端API/1451-robots-send-interactive-cards.md) |
| 更新机器人发送互动卡片 | 机器人更新发送的互动卡片。 | [更新机器人发送互动卡片（普通版）](../../01-应用开发/02-4a8AMF6u2A-服务端API/1452-update-the-robot-to-send-interactive-cards.md) |
