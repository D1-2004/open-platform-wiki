# 互动卡片高级版编辑器

## 编辑器整体结构简介

如图所示，卡片编辑器主要由四个部分组成：

1. 顶部操作栏（图示①）
2. 左侧菜单面板区（图示②）
3. 中间编辑画板区（图示③）
4. 组件属性设置区（图示④）![1642647985972-16193de7-8a79-49c3-8061-8851f4982979.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0260662461/p389775.png)

## 顶部操作栏

顶部操作栏总共分为以下左右两个部分。

- **操作栏左半部分**：![1642647986393-c47c0d62-226a-4155-a2b6-495cc355c125.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0969562461/p389776.png)如图所示，左半部分主要包含了**返回按钮**以及**模板名称的展示**。

  其中，通过点击返回按钮可以返回至**该卡片模板的列表页**，如图所示：![1642647986799-0f305ff1-01fa-4704-a8da-d37af3ad3266.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0969562461/p389777.png)
- **操作栏右半部分**：![1642647987238-3a33ae38-cb5c-4051-8988-344d873f3392.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0969562461/p389778.png)右半部分多为操作按钮，如图所示从左到右分别是：

1. **后退、前进按钮**：用以撤销、还原上次的编辑操作。
2. **更新日志查看按钮**：点击用以查看编辑器的更新日志，了解新功能信息等。
3. **帮助文档查看按钮**：点击将跳转至编辑器的使用文档页面。
4. **导出按钮**：点击导出当前模板所有信息的 JSON 描述文件，用以导入使用。
5. **导入按钮**：可以导入通过导出得到的模板 JSON 文件，并覆盖当前的卡片模板。
6. **复制模板按钮**：重新创建一个当前模板的克隆副本。
7. **保存按钮**：手动保存当前卡片模板的所有信息。
8. **发布按钮**：将卡片模板进行发布（注意：模板一旦发布后便无法再次编辑）。

## 左侧菜单面板区

![1642647987739-3d9d976c-44a0-47f6-8af8-a7f78735d211.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389779.png)如图所示，左侧菜单面板区共分为四个模块，从上往下分别是：**大纲树**、**组件库**、**预设模板**以及**数据源**。

- **大纲树面板**

  **该模块主要展示的是当前卡片的大纲视角（总览视角）**，能够直观的看到当前卡片的所有组件以及嵌套信息，并进行快速选中和拖拽操作。

  当选择某一个组件时，可以查看当前卡片内容在编辑画板区域的状态和位置，在组件较多的状态下方便编辑。

  如图所示，在大纲中选中图片组件，卡片对应的组件将会同步高亮：![1642647988779-eb4ad0ba-13ee-4b6d-9160-b5494d1f2227.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389780.png)
- **组件库面板**

  **组件库是编辑卡片模板的核心操作区域**。通过长按拖拽不同的组件，可以组成最终的互动卡片。根据互动卡片的构成元素，组件共有四个分类：**头部元素、内容元素、布局元素以及操作区。**

  一个完整的互动卡片，每一部分的元素都缺一不可，拖动不同的组件到画板区，就可以生成不同的互动卡片。同时，拖拽过程中可以在右侧面板中看到其在大纲的相应位置，如图：![1642647989470-27ec5795-f3cb-4064-839b-d30cde8460ee.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389781.png)
- **预设模板面板**![1642647990029-cc8fee2b-cb65-4025-a657-339799c9788f.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389782.png)预设模板面板中包含了许多常见的卡片模板，如日志模板、审批模板、日程模板等。每个预设模板都有“使用”和“预览”按钮。

  - **使用**：可以快速使用当前预设模板的相关内容，此操作将会覆盖当前编辑中的卡片模板
  - **预览**：预览将会跳转至该卡片搭建态的页面，不会影响当前正在编辑中的卡片模板。
- **数据源面板**

  数据源面板为**变量列表**以及**卡片模拟数据**（以下称为 Mock 数据）的编辑区域。

  - **变量列表**

    该面板展示了当前卡片所有变量的列表，并可以在此进行变量的增删改操作。

    如果没有变量，那么卡片将会是固定不变的，也是意义不大的。变量为动态卡片注入灵魂并带来了更多的可能性。**因此可以简单地理解：变量为卡片提供了动态的数据**。![1642647990436-7ffb0bf2-266f-4cef-9968-e31990ca65f1.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389783.png)如图，变量共分为**普通变量**和**表达式变量**两种类型。

    - **普通变量**

      点击编辑普通变量即可对普通变量进行批量编辑。![1642647991016-ab28e191-c0b7-49df-ac78-3abce64c1469.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389784.png)如上图所示，新增变量时需要填入变量的**变量名、变量类型**，变量描述为可选填入。

      如下图所示，变量的操作列中的按钮功能如下：![1642647991411-43af27d6-bea2-4d94-a094-79115914ac20.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389785.png)1.**是否设置为私有变量**：如设置为私有变量，则代表该变量的值将会千人千面，即不同人看到的值不同。例如点赞的场景，即是私有变量的应用场景。

      2.**复制变量**：快捷新增一个变量的复制副本。

      3.**删除变量**

      4.**编辑单个变量的 Mock 数据**

      编辑完成后点击“保存”即可进行变量的更新。
    - **表达式变量**

      表达式变量是对 n 个普通变量的引用与计算。由于编辑变量时与普通变量相似，此处不过多赘述，主要讲**表达式内容**的填写。

      举个简单的例子：假设有变量number的值为1，同时有变量 number2 的值为2

      如图所示的表达式变量最终将会得到结果：3。![1642647992060-b90d39a9-81be-4e1d-bcb8-bde9855ef10f.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389786.png)更多的语法与结合使用请点击文本框后的图标按钮进行查看。
  - **Mock 数据**

    该面板可以对当前的所有的普通变量进行数据模拟，变量在卡片中被引用时将会使用其 Mock 的值（后面会介绍如何将变量与组件的属性进行绑定）。![1642647992685-a30f3bf4-950d-4f7e-8f46-5522d8ae8cde.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389787.png)如图，Mock 数据还分为**公有数据**以及**私有数据**，公有数据就是对公有变量的数据模拟，相反，私有数据即是对私有变量的数据模拟，这取决于该变量是否被标识为私有变量。

## 中间编辑画板区1642647993222-25301748-ebc4-40c7-a433-ee67373d112d.png

  - **模拟选项**
  - **模拟暗黑模式**：如图，启动后将采用暗黑模式样式渲染卡片，你可以对暗黑模式下的卡片进行预览以及适当地调整。![1642647994198-e88f0010-80aa-49c6-a337-f4276b694ce4.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389790.png)

  - **模拟语言**：用于国际化卡片测试，可以切换简体、繁体、英文、日文、越南文、泰文以及印尼文共七中语言。

  - **布局调整**

## 组件属性设置区

以基础文本组件为例，选中后其属性设置区如图所示：![1642647997303-5f84e515-cc86-428c-bb83-9c3492bc0cf4.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389796.png)可见，基础文本组件包含内容、最大行数、图标、对齐方式、文字颜色、尺寸、行高等属性。

为了方便描述与理解，这里要引入两个简单的概念进行区分：**静态属性**和**混合属性**。

- **静态属性**

  所谓静态属性，即**设置的值是永远不变的**。

  如基础文本的“对齐方式”属性，设置为左对齐，那么其对齐方式就永远显示为左对齐；“文字颜色”设置为橘黄色，显示的文本颜色就将永远为橘黄色。同理，文字尺寸、行高等也为静态属性。
- **混合属性**

  与静态、动态属性不同，混合属性可以是静态的、也可以是动态的，它是可以绑定变量的，即**设置的值可能是变化的也可能是不变的**。

  当属性设置区的展示形式如下图示时，即可断定其为混合属性：

  - **形式一**：![1642647997729-2e559463-1d6e-4170-80ad-b3100d7913db.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389797.png)这看似是一个普通的文本输入框，实际上它还可以通过${variableName} 占位符的形式来表示变量引用。

    以基础文本组件的内容属性为例，我们有一个变量appName，并且 Mock 值为阿里味， 因此当混合属性输入我是${appName} 时卡片最终渲染的基础文本内容即为我是阿里味，如图所示：![1642647998372-26b1606e-8435-4e90-82b2-62adaf86bfb4.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389798.png)同理，如果要取循环数组里面的变量，则可以通过${loop.variableName} 的形式来表示。
  - **形式二**：![1642647999015-2fcea506-7a45-441f-af0d-0b64aa7d39b5.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389799.png)如图，可见有两个单选框分别为**固定值**（或其他文案）和**绑定变量**。

    以基础文本的最大行数属性为例：

    - 当选中**固定值**时，将呈现一个数字输入框，与正常的数字类型静态属性没有区别，如左边距属性设置：![1642647999542-f06630d1-eaa2-4d82-9476-a004cb7b61ba.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389800.png)
    - 当选中**绑定变量**时，将会通过下拉框显示符合条件的变量列表，因为此例中是数字类型的属性，因此只能绑定数字类型的变量（其他类型同理）：![1642648000039-b4a32afc-4087-4af5-98aa-f75956a863ba.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389801.png)综上所述，我们可以得出对于基础文本组件来说，易得“内容”、“最大行数”以及“图标”三个属性均为混合属性。
